# 容灾切换

容灾切换持续探测解析记录，失败达到确认次数后自动切换到备用记录、暂停解析或条件开启解析。

## 创建策略

1. 打开“容灾切换 → 切换策略”。
2. 点击“添加策略”。
3. 选择域名与主机记录。
4. 点击“获取”加载解析记录。
5. 选择主记录与备用记录。
6. 配置检测协议与切换设置。
7. 保存并启用运行。

## 检测协议

| 协议 | 说明 |
| --- | --- |
| Ping / ICMP | 检测主机可达性 |
| TCP | 检测指定端口 |
| HTTP / HTTPS | 请求完整 URL，状态码须为 2xx 或 3xx |

HTTP 检测可以设置指定 IP、超时、是否使用代理，以及最大超时时间。最大超时不能大于检测间隔。

## 备用记录

备用记录支持 IP 或 CNAME。可以设置：

- Cloudflare 代理：切换时同时开启代理模式。
- 确认次数：连续失败多少次后切换。
- 检测间隔：多久检测一次。
- 条件开启解析：与暂停解析配合，当同域名正常记录数量小于等于阈值时开启解析。

## 切换动作

策略可以配置：

- 切换备用解析。
- 暂停解析。
- 条件开启解析。
- 恢复主解析。

异常恢复后是否自动恢复由策略与记录状态决定。切换与恢复都会写入切换记录。

## 运行概览

“运行概览”展示：

- 调度运行状态。
- 累计检测次数。
- 最近运行时间。
- 24 小时切换次数。
- 24 小时告警次数。
- 运行日志与错误。

## 立即重试

策略行的“重试”或批量“立即重试”会立即发起一次检测，不等待下一个周期。也可以调用 `/api/dmonitor/tasks/:id/run`。

## 切换记录

进入策略详情可以按操作类型筛选：

- 发生异常。
- 恢复正常。
- 切换备用。
- 开启解析。
- 恢复主解析。

记录包含时间、异常原因与切换目标。

## 批量操作

勾选多个策略可以批量开启、停止或立即重试。批量操作会逐个执行，失败项单独提示。

## 日志清理

管理页可以清理指定天数之前的切换日志。清理不影响策略本身。

## 与其他模块的关系

- 容灾切换会修改 DNS 解析，可能与定时切换任务冲突。
- 证书验证、CDN 联动也可能修改记录，变更前确认优先级。
- 切换通知走系统通知通道。

## 常见问题

### 一直不切换

检查策略是否运行、检测间隔、确认次数、超时设置与备用记录是否有效。

### 频繁切换

可能是探测目标不稳定或网络抖动。增加确认次数与间隔，或改用更稳定的检测 URL。

### 切换后未恢复

确认主记录恢复检测通过，并检查策略是否允许自动恢复。
