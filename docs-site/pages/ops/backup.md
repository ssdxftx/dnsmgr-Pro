# 备份与恢复

“备份与恢复”包含站点备份、我的备份与凭证保险库。

## 备份类型

- 整站备份：管理员导出站点配置、用户、账户、域名、任务、审计等数据。
- 个人备份：普通用户导出自己的云账户、域名授权、任务与个人操作日志。
- 远端备份：上传到 WebDAV 或 S3 兼容存储。
- 计划备份：按每天或每周执行，自动清理过期归档。

归档格式为 `.dnsmgrbk`，使用 AES-256-GCM 加密，并对归档头做 HMAC 签名。

## 备份密钥

整站备份使用独立备份密钥。页面可以查看状态、生成或轮换密钥。

轮换后旧备份仍需要旧密钥恢复。请把密钥保存在密码管理器或外部密钥系统中。

如果服务端设置了 `DNSMGR_BACKUP_KEY`，密钥由环境变量托管，页面不能轮换。生成方式：

```bash
openssl rand -base64 32 | tr '+/' '-_' | tr -d '='
```

## 立即备份

1. 打开“系统设置 → 备份与恢复”。
2. 选择“站点备份”。
3. 选择是否包含操作日志。
4. 选择备份目的地。默认仅本地。
5. 点击“开始备份”。

备份历史展示时间、范围、大小、状态、目的地与操作。

## 备份目的地

### WebDAV

填写可写目录地址、用户名与密码。坚果云根目录 `/dav/` 只读，需要填写 `/dav/我的坚果云/` 或其子目录。

### S3

填写 Endpoint、区域、Bucket、AccessKey、SecretKey 与目录前缀。支持 S3 兼容存储。

添加后先测试连接。读取远端列表时可以浏览、下载、删除归档，并选择整站备份在线恢复。

## 计划备份

1. 点击“添加计划”。
2. 填写计划名称。
3. 选择每天或每周。
4. 设置小时与分钟。
5. 选择星期。
6. 设置保留份数与保留天数。
7. 启用并保存。

可以立即执行一次计划。保留策略会同时按份数与天数清理。

服务端默认值可用环境变量调整：

```bash
DNSMGR_BACKUP_KEEP_COUNT=10
DNSMGR_BACKUP_KEEP_DAYS=30
DNSMGR_PRE_RESTORE_KEEP_COUNT=5
DNSMGR_PRE_RESTORE_KEEP_DAYS=14
```

## 在线恢复

1. 在备份历史或云端备份中选择“恢复”。
2. 选择恢复方式：替换或合并。
3. 输入 `RESTORE` 确认。
4. 开始恢复。

替换模式会清空现有业务数据后写入备份内容，恢复后需要重新登录。合并模式保留现有数据，只补充备份中的记录。

恢复前系统会自动生成当前站点快照。恢复期间进入维护模式，阻止用户写入。

恢复完成前不要关闭页面。失败时系统仍处于维护模式，可以重试或手动退出。

退出维护模式需要输入 `EXIT`。仅在确认数据已恢复或准备放弃本次恢复时使用。

## 个人备份

普通用户在“我的备份”中导出或导入自己的数据。

- 导出包含私有云账户、域名授权、解析任务与个人操作日志。
- 口令模式导出时需要输入保险库口令。
- 导入只支持本人导出的归档。
- 支持仅预检。

便捷模式下，整站备份中的私有凭证可由管理员解密。敏感凭证建议使用口令模式。

## 安装时导入

初始化安装成功后可以直接导入整站或口令备份。需要安装令牌与备份密钥或口令。导入完成后应用重启。

## 远端归档删除

管理员可以删除远端备份归档。删除会同时删除文件，先确认没有恢复需求。

## 恢复后检查

1. 使用管理员登录。
2. 检查用户、域名、账户、证书与任务数量。
3. 检查调度器是否运行。
4. 检查通知与备份计划。
5. 检查 API Key 与旧版密钥状态。
6. 退出维护模式并验证写入。

## 常见问题

### 恢复后无法登录

替换模式会恢复备份中的用户数据。使用备份时的管理员账号登录。

### 备份失败

检查数据目录权限、磁盘空间、远端存储连通性与密钥状态。

### 口令归档无法导入

确认输入的是导出时设置的口令。口令错误无法解密。

### 备份文件很大

备份包含附件、日志与任务记录。可以排除操作日志，或调整保留策略。
