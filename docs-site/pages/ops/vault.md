# 凭证保险库

凭证保险库用于保存普通用户的私有云账户。私有账户只在创建者本人的会话里可见与使用，其他用户（含管理员）无法通过接口读取。

两种模式的隔离强度不同：**口令模式**下数据密钥只由用户口令包裹，管理员即使拿到数据库也无法解密；**便捷模式**下数据密钥由系统密钥（`sys_key`）包裹，任何能读到系统密钥的人（例如能登录服务器或导出数据库的管理员）都可以解密。需要真正的“管理员也不可读”，请使用口令模式。

## 启用保险库

1. 打开“备份与恢复 → 凭证保险库”。
2. 选择模式：
   - 口令模式：使用独立口令加密，管理员无法解密，推荐。
   - 便捷模式：由系统托管密钥，登录即用，管理员可解密。
3. 口令模式需要设置至少 12 个字符的口令，并确认口令。
4. 便捷模式需要勾选风险确认。
5. 点击启用。

## 模式差异

| 能力 | 口令模式 | 便捷模式 |
| --- | --- | --- |
| 独立口令 | 需要 | 不需要 |
| 管理员可解密 | 否 | 是 |
| 登录后直接使用 | 需解锁 | 是 |
| 整站备份 | 可配置排除 | 可包含 |
| 适用场景 | 敏感凭证 | 低敏感、追求便利 |

## 解锁与锁定

口令模式在访问私有凭证前需要解锁。解锁后可以：

- 查看与使用私有 DNS、CDN、证书账户。
- 导出个人备份。
- 修改口令。
- 生成恢复码。

使用完毕后可以手动锁定。

## 添加私有账户

1. 启用并解锁保险库。
2. 切换到 DNS、CDN 或证书标签。
3. 添加账户并填写凭证。
4. 保存。

私有账户在对应业务模块中只对创建者可见，接口不会把明文返回给管理员。注意这属于“接口层面的隔离”：便捷模式的密钥托管在系统密钥里，管理员仍可通过数据库与系统密钥解密，详见 [模式差异](#模式差异)。

## 恢复码

忘记口令时可以生成恢复码。恢复码只显示一次，请保存在安全位置。

生成新恢复码会立即使旧恢复码失效。使用恢复码可以重置口令。

## 修改口令

输入当前口令与新口令即可修改。修改后旧口令失效。

## 升级与降级

- 便捷模式可以升级为口令模式。
- 口令模式可以降级为便捷模式。

降级前确认可以接受管理员可解密私有凭证的风险。模式切换会影响后续加密与备份行为。

## 排除整站备份

口令模式可以开启“不参与整站备份”。开启后，整站备份不会包含该用户的保险库与私有账户。

这适合私有凭证不应进入站点级备份的场景。关闭后需要自行确保个人备份可用。

## 销毁保险库

销毁会删除保险库与全部私有凭证，且不可恢复。需要输入 `DESTROY` 并再次确认口令或登录密码。

销毁前先导出个人备份，或把凭证迁移到其他位置。

## 安全建议

- 敏感凭证使用口令模式。
- 口令与登录密码不同。
- 恢复码离线保存。
- 不要把保险库口令写入脚本或仓库。
- 定期检查私有账户是否仍在使用。

## 常见问题

### 忘记口令

使用恢复码重置。没有恢复码时无法解密口令模式数据。

### 解锁后仍看不到账户

确认账户属于当前用户，且保险库已解锁。刷新页面后重新进入模块。

### 管理员看不到用户私有账户

这是预期行为。普通用户的私有账户只在所有者本人的会话里可见：接口层面按 `owner_uid` 隔离，管理员也不能借用他人的私有凭证。

但“管理员完全无法解密”只在口令模式成立。便捷模式的 DEK 由系统密钥包裹，能读到 `sys_key` 的人可以解密，因此不要把便捷模式当作对管理员的加密隔离。
