# 运维与自动化

运维模块把故障切换、定时变更、线路优选与数据保护集中管理。

## 模块

- [容灾切换](/ops/failover)：探测主记录，失败后自动切换备用。
- [定时切换](/ops/schedule)：按时间计划修改、启用、暂停或删除解析。
- [CF 优选 IP](/ops/optimize-ip)：自动更新 Cloudflare 优选线路。
- [备份与恢复](/ops/backup)：整站与个人加密备份、在线恢复、计划备份。
- [凭证保险库](/ops/vault)：普通用户的私有云账户与口令保护。

## 调度器

系统内置调度器，随服务启动自动运行：

- 容灾监控。
- 定时切换。
- CF 优选 IP。
- 自动续签与部署。
- 到期扫描。
- 劫持检测。
- 自动预热与刷新。
- 统计缓存。

不需要额外配置 cron。系统设置中的 cron URL 仅用于兼容旧版外部触发，密钥应通过 `X-Cron-Key` 请求头传递。

## 运行状态

“容灾切换 → 运行概览”展示累计检测次数、最近运行时间、24 小时切换次数与告警次数。其他任务在各自列表展示上次执行与下次执行。

## 操作建议

- 自动化任务先在测试域名验证。
- 修改解析的任务要确认没有与容灾策略冲突。
- 大批量操作前先备份。
- 定期检查任务失败记录与通知投递历史。
