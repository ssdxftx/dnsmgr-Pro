# 定时切换

定时切换按计划修改解析记录，适合固定时间切换源站、启停解析或删除临时记录。

## 创建策略

1. 打开“容灾切换 → 定时切换”。
2. 点击“添加策略”。
3. 选择域名与主机记录。
4. 点击“获取”加载解析记录。
5. 选择目标记录。
6. 选择执行方式与时间。
7. 配置切换动作。
8. 保存并启用。

## 执行方式

### 单次执行

在指定时间执行一次。执行完成后策略不再重复。

### 周期执行

支持：

- 每天。
- 每周，选择星期几。
- 每月，选择日期 1 到 31。
- 间隔执行。

具体时间按 24 小时制填写。每月 29、30、31 日在不存在的月份按调度规则处理。

## 切换动作

| 动作 | 说明 |
| --- | --- |
| 修改解析 | 修改记录值为指定 IP 或 CNAME |
| 启用解析 | 让暂停的记录恢复生效 |
| 暂停解析 | 保留记录但停止解析 |
| 删除解析 | 删除记录 |

修改解析时可以同时设置线路：

- 不修改线路。
- 改为仅 DNS 模式。
- 改为代理模式。

只适用于支持对应能力的服务商。

## 批量操作

勾选策略可以批量：

- 开启运行。
- 停止运行。
- 删除。

批量操作会逐个执行并返回结果。

## 运行状态

列表展示：

- 下次执行。
- 上次执行。
- 近 24 小时执行次数。
- 运行状态。
- 关键词、域名、记录 ID、记录值与备注。

## 立即执行

管理员可以调用 `/api/schedule/tasks/:id/run` 立即执行一次。页面上的批量操作也提供立即执行入口。

## 与容灾切换的冲突

定时切换与容灾切换都会修改同一条记录。两者同时命中时，后执行的任务会覆盖前一个结果。

建议：

- 关键记录只启用一种自动切换。
- 如果两者都需要，使用不同的记录或明确时间窗口。
- 定期检查切换记录，确认最终状态符合预期。

## 常见问题

### 策略没有执行

检查是否启用、时间设置是否正确、调度器是否运行，以及记录是否仍存在。

### 修改记录失败

确认记录 ID 未变化、账户有写权限、记录值与类型匹配。

### 删除后无法恢复

删除解析会移除记录。需要保留时使用暂停解析。
