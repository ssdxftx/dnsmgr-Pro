# 初始化安装

首次访问 `http://服务器IP:8082` 会自动进入系统安装页。

## 安装前准备

1. 确认 `/app/data` 已持久化，或已准备好 MySQL 数据库。
2. 从启动日志获取安装令牌，或提前设置 `DNSMGR_SETUP_TOKEN`。
3. 准备管理员账号与强密码。
4. 如要绑定已有彩虹 DNS 数据库，准备原数据库连接信息与表前缀。

查看安装令牌：

```bash
docker logs dnsmgr-pro 2>&1 | grep -i setup
```

## 选择数据库

### SQLite

适合单实例、小规模部署。安装页只有在检测到持久化目录时才允许选择 SQLite。

- 数据文件位于 `DNSMGR_DATA_DIR/dnsmgr.sqlite`。
- WAL 文件与锁文件位于同一目录。
- 不支持多副本与 NFS/CIFS 共享存储。
- 第二个实例会因锁文件拒绝启动。
- 非持久化目录会回退到 MySQL，避免数据写入临时文件系统。

### MySQL

适合多用户、多副本或已有数据库环境。需要提前创建数据库和账号：

```sql
CREATE DATABASE dnsmgr CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'dnsmgr'@'%' IDENTIFIED BY '请替换为强密码';
GRANT ALL PRIVILEGES ON dnsmgr.* TO 'dnsmgr'@'%';
FLUSH PRIVILEGES;
```

安装页填写：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| 数据库主机 | `mysql` 或 `127.0.0.1` | Compose 内置数据库填服务名 |
| 数据库端口 | `3306` | MySQL 默认端口 |
| 数据库用户名 | `dnsmgr` | 需要建表权限 |
| 数据库密码 | 强密码 | 不要使用示例值 |
| 数据库名 | `dnsmgr` | 需提前创建 |
| 表前缀 | `dnsmgr_` | 绑定彩虹 DNS 时填写其实际前缀 |
| 安装令牌 | 启动日志中的值 | 也可由环境变量固定 |

## 测试连接

点击“测试数据库连接”后会出现两种结果：

- 连接成功且未初始化：执行全新安装，需要填写管理员账号与密码。
- 检测到已有数据：绑定现有数据库，不会删除或覆盖原有域名、用户、证书与任务。

全新安装的管理员密码至少 8 位。用户名建议使用非默认值。

## 导入已有备份

全新安装成功后，页面会显示“导入已有备份（可选）”，并提供一次性安装令牌。

- 整站归档：填写备份密钥（32 字节 Base64URL）。
- 口令归档：填写备份口令。
- 导入完成后应用自动重启。
- 不需要导入时点击“跳过此步”，应用也会重启。

安装令牌 10 分钟内有效。导入接口只在该窗口内接受请求。

## 安装完成后的重启

安装成功时后端会主动退出，让容器编排或守护进程重新启动进程并加载完整业务路由与调度器。

Docker 与 Kubernetes 会自动重启。宿主机运行时需要手动重启进程：

```bash
sudo systemctl restart dnsmgr-pro
```

重启完成后使用管理员账号登录。

## 安装后的检查

1. 仪表盘能正常加载。
2. “关于”页面显示前后端版本一致。
3. 系统设置中通知配置可发送测试消息。
4. 备份页面可创建一次整站备份。
5. 若使用 HTTPS，确认反向代理传递 `X-Forwarded-Proto` 并设置 `DNSMGR_TRUST_PROXY`。

## 常见问题

### 提示安装令牌不正确

检查启动日志中的令牌，或确认环境变量 `DNSMGR_SETUP_TOKEN` 与页面填写一致。令牌区分大小写。

### SQLite 选项不可用

确认 `/app/data` 是持久化卷或绑定挂载。无法识别挂载信息时设置 `DNSMGR_DATA_PERSISTENT=1`。

### 数据库连接失败

检查数据库地址、端口、账号权限与数据库是否已创建。容器内连接宿主机数据库时不要填写 `127.0.0.1`，应填写宿主机可达地址或 `host.docker.internal`。

### 安装完成但页面一直加载

等待容器重启完成。查看日志：

```bash
docker logs --tail=200 dnsmgr-pro
```
