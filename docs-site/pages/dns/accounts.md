# DNS 账户

DNS 账户保存云厂商授权信息。一个账户可以导入多个域名。

## 添加账户

1. 打开“域名管理 → DNS 账户”。
2. 点击“添加账户”。
3. 选择服务商。
4. 填写账户名称与备注，便于区分环境或项目。
5. 按服务商要求填写 AccessKey、Secret、API Token、用户名密码或其他凭证。
6. 点击“保存并验证”。

验证失败时先检查凭证权限、IP 白名单、API 是否启用与账户是否欠费。部分服务商需要额外开通 DNS 产品。

## 凭证安全

- 账户凭证使用 AES-256-GCM 加密落库。
- 接口回显统一脱敏。
- 账户配置无法解密时，列表会标记“配置异常”。此时需要重新填写全部凭证后保存。
- 普通用户的私有账户保存在凭证保险库，管理员无法查看明文。

## 编辑与删除

编辑账户时可以修改名称、备注与凭证。保存时会重新验证。

删除账户前确认没有域名、任务或授权依赖。删除后关联域名将无法继续通过该账户读写云端解析。

## 共享账户与私有账户

管理员创建的账户是共享账户。普通用户在“备份与恢复 → 凭证保险库”中创建的 DNS 账户是私有账户：

- 便捷模式由系统托管密钥，登录即用，管理员可解密。
- 口令模式使用独立口令加密，管理员无法解密，推荐用于敏感凭证。

## 服务商差异

| 能力 | 说明 |
| --- | --- |
| 线路 | 阿里云、DNSPod、华为云等支持多线路；部分海外厂商只有默认线路 |
| 权重 | 仅阿里云支持权重解析 |
| 别名 | 仅 DNSPod 支持域名别名 |
| 解析日志 | 仅阿里云支持记录操作日志 |
| CNAME 代理 | 与证书 DNS-01 验证配合使用 |
| 代理模式 | Cloudflare 支持代理开关 |

## 常见问题

### 账户验证成功但拉取不到域名

确认账号下确实有域名，且 API 凭证具备读取域名列表的权限。部分厂商需要指定项目、账号 ID 或区域。

### 配置异常

通常是系统密钥变更或数据迁移导致旧密文无法解密。重新填写凭证即可恢复。

### 想限制某个账户只给一个用户使用

管理员账户用于共享；如果凭证只应给单个用户，建议由该用户在凭证保险库中创建私有账户。
