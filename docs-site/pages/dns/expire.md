# 到期提醒

到期提醒通过 WHOIS 或 RDAP 获取域名注册与到期时间，并按配置的节点发送通知。

## 配置提醒

1. 打开“域名管理 → 到期提醒”。
2. 填写“到期提醒天数”，例如 `7,14,30`。
3. 选择通知渠道。
4. 保存。

留空表示不开启到期提醒。多个天数用英文逗号分隔，系统会在到期前对应天数发送通知。

## 通知渠道

- 邮件
- 微信公众号 WxPusher
- Telegram 机器人
- QQ 机器人
- 群机器人 Webhook（企业微信、钉钉、飞书）
- 自定义 Webhook

渠道参数在“系统设置 → 通知设置”中配置。发送前建议先做测试。

## 刷新到期时间

域名列表的“刷新到期时间”会：

1. 优先查询 RDAP。
2. 回退到 WHOIS。
3. 解析注册时间与到期时间。
4. 写回域名记录。

查询失败时保留原值。部分后缀的注册局限制查询频率，短时间内重复刷新可能失败。

## 批量发送

管理员可以在到期提醒页面执行批量发送，用于补发或验证通知链路。批量发送会按当前域名与配置生成消息。

## 提醒不发送的排查

1. 确认域名的“到期提醒”开关已开启。
2. 确认到期时间已成功查询。
3. 确认提醒天数包含当前剩余天数。
4. 在系统设置中发送测试消息。
5. 查看“通知投递历史”和操作日志中的失败原因。

## 建议

- 至少提前 30 天开始提醒。
- 生产域名同时配置邮件与即时消息。
- 定期刷新到期时间，避免注册商变更导致信息过期。
- 对已不再使用的域名关闭提醒。
