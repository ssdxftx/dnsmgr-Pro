# 劫持检测

劫持检测把本地解析结果与 DoH 结果或预期值比对，发现异常时发送邮件告警。

## 创建任务

1. 打开“域名管理 → 劫持检测”。
2. 点击“添加任务”。
3. 填写任务名称，便于识别。
4. 选择域名。
5. 选择子域名范围。留空表示检测整个域名。
6. 选择记录类型。留空表示全部类型。
7. 选择执行周期：每日定时或间隔执行。
8. 填写提醒邮箱。留空使用系统默认收件邮箱。
9. 保存。

## 子域名范围

选择子域名后，系统检测该子域名的下级。例如选择 `user1` 会检测 `user1.example.com` 下的三级及更深记录。

## 检测结果

结果列展示：

- 正常。
- 异常数量。
- 未检测。
- 最近一次检测时间。

异常详情包含主机记录、期望值、本地解析值与实际状态。Cloudflare 代理记录会标记为“已开启 Cloudflare 代理”，避免误报。

## 立即检测

任务行的“立即检测”会立即执行一次，不受周期限制。执行结果写入检测记录，并参与异常告警。

## 告警

发现异常时发送邮件，内容包含异常记录与可能原因。通知渠道与发信配置来自系统设置。

## 调度

内置调度器会按每日时间或间隔分钟执行任务。服务启动后自动加载，不需要外部 cron。

## 排查建议

- 先用公共 DNS 查询确认异常是否真实存在。
- 检查域名 NS 是否被修改。
- 检查本地递归解析器是否被污染。
- 检查记录是否刚修改，TTL 尚未过期。
- 对 Cloudflare 代理记录关注源站与代理状态。

## 删除任务

删除任务只停止检测，不会修改解析记录。历史检测记录按系统保留策略处理。
