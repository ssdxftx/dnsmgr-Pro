# 解析记录

进入“域名列表”后点击域名，即可查看和维护该域名的解析记录。

## 新增记录

1. 点击“添加记录”。
2. 填写主机记录。根域名使用 `@`，例如 `www`、`api`、`mail`。
3. 选择记录类型。
4. 填写记录值。
5. 按需填写线路、TTL、优先级与备注。
6. 保存。

常见记录类型：

| 类型 | 用途 | 示例值 |
| --- | --- | --- |
| A | IPv4 地址 | `203.0.113.10` |
| AAAA | IPv6 地址 | `2001:db8::10` |
| CNAME | 域名别名 | `origin.example.com` |
| MX | 邮件服务器 | `mx.example.com`，设置优先级 |
| TXT | 文本验证、SPF | `v=spf1 include:example.com ~all` |
| NS | 子域委派 | `ns1.example.com` |
| SRV | 服务定位 | 按服务商格式填写 |
| CAA | 证书颁发机构限制 | `0 issue "letsencrypt.org"` |
| REDIRECT_URL | 显式跳转 | 按服务商支持填写 |
| FORWARD_URL | 隐式跳转 | 按服务商支持填写 |

不同服务商对类型、线路与 TTL 的支持不同，保存失败时以页面返回的错误为准。

## 编辑与启停

记录行支持编辑、暂停、启用、删除和检测。暂停记录会保留内容但停止解析生效。

修改记录值、线路、优先级或 TTL 会直接写入云端。操作会进入审计日志。

## 批量操作

勾选同一域名下的多条记录后可以：

- 批量启用、暂停、删除。
- 批量修改记录值。
- 批量修改线路。
- 批量修改备注。
- 移动到分组。

批量操作只支持同一域名下的记录。跨域名操作请分批执行。

## 文本批量导入

进入“解析记录 → 导入”后，每行填写一条：

```text
www 203.0.113.10
@ 203.0.113.10
api cname.example.com
```

系统会自动识别记录类型。需要固定类型时在导入页选择类型。导入前建议先用少量记录验证格式。

## 解析检测

记录行的“检测”会查询实际解析值并与期望值比对：

- 解析值一致：正常。
- 解析值不一致：可能被劫持或尚未生效。
- 未查询到记录：检查 NS、TTL 与云端状态。
- Cloudflare 代理：会提示已开启代理，实际值为代理地址。

## 记录日志

阿里云账户支持解析日志。进入域名菜单“解析日志”可以查看操作时间、主机记录与记录 ID。其他服务商不提供该能力。

## 权重解析

阿里云支持权重解析。进入“权重解析”后可以为同一子域名的多条记录分配权重，并开启或关闭权重。权重总和与线路规则按阿里云要求执行。

## 域名别名

DNSPod 支持域名别名。进入“域名别名”添加别名域名后，别名共享同一份解析记录。别名需要先在服务商侧满足可用条件。

## 常见问题

### 添加记录失败

确认域名 NS 已指向当前服务商，账户凭证有写权限，记录值符合类型要求。

### 修改后不生效

等待 TTL 过期并用公共 DNS 查询。也可以使用记录行的检测功能比对实际解析值。

### 记录被云端删除

本地列表以云端为准。刷新记录页即可同步最新状态。
