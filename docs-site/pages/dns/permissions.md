# 域名授权与权限

普通用户只能访问被授权的域名与子域名。管理员在“系统设置 → 用户管理”中分配。

## 授权模型

一条授权包含：

| 字段 | 说明 |
| --- | --- |
| 域名 | 要被授权的本地域名 |
| 子域名前缀 | 留空表示整个域名；填写 `user1` 或 `a.user1` 表示该前缀及其下级 |
| 有效期 | 留空表示永久 |
| 只读 | 开启后只能查看，不能新增、修改或删除 |
| 自由解析 | 允许用户自行新增、修改、删除授权范围内的解析 |
| 检测整域名 | 允许用户对授权域名配置整个域名的劫持检测 |

## 分配授权

1. 打开“系统设置 → 用户管理”。
2. 找到目标用户，点击编辑。
3. 在“子域名分配”中点击“添加子域名授权”。
4. 选择域名。
5. 填写子域名前缀。留空表示整域名。
6. 按需设置有效期、只读与自由解析。
7. 保存。

用户下次请求时会立即按新权限校验。

## 子域名前缀规则

- 留空：整个域名。
- `user1`：`user1.example.com` 及其下级。
- `a.user1`：`a.user1.example.com` 及其下级。

用户只能看到授权范围内的记录。越权请求按对象不存在处理，不会泄露其他域名信息。

## 只读与自由解析

只读权限优先级最高。开启只读后，即使用户拥有自由解析也不能写入。

自由解析用于允许用户自行维护授权范围内的记录。关闭后用户只能查看，记录变更由管理员完成。

## 检测整域名

默认情况下，普通用户的劫持检测范围受子域名授权限制。开启“检测整域名”后，用户可以配置覆盖整个授权域名的检测任务。

## 管理员权限

管理员可以：

- 查看和管理全部域名。
- 管理 CDN、证书、部署、容灾与系统设置。
- 创建、编辑、封禁、删除用户。
- 管理用户 API 接口与统计缓存权限。
- 管理全部 API Key（通过 `uid` 查询）。

超级管理员拥有全部权限，并保证系统中恰好存在一个超级管理员。

## API Key 的权限叠加

API Key 的作用域只限制可访问的模块。即使 Key 拥有 `dns:write`，普通用户仍只能操作被授权的域名。管理员等级校验与域名授权会同时执行。

## 检查授权是否生效

1. 用普通用户登录。
2. 域名列表应只显示授权域名。
3. 打开只读域名，新增与删除按钮应不可用。
4. 用 API Key 请求未授权域名，应返回无权限或对象不存在。

## 常见问题

### 用户看不到域名

确认授权已保存、域名未被隐藏、授权未过期，并且域名属于共享账户。

### 用户能看但不能改

检查是否开启只读。只读会覆盖自由解析设置。

### 子域名授权范围过大

把前缀写得越具体，范围越小。需要精确到单个主机记录时填写完整前缀，例如 `www.user1`。
