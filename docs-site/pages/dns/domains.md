# 域名列表

“域名列表”是本地纳管域名的入口。只有导入到本地的域名才能使用解析记录、提醒、劫持检测和授权。

## 导入域名

1. 打开“域名管理 → 域名列表”。
2. 点击“导入域名”。
3. 选择 DNS 账户。
4. 系统拉取云端域名列表。
5. 勾选需要纳管的域名。
6. 点击“导入所选”。

导入只创建本地域名记录，不会修改云端解析。重复导入会跳过或复用已有记录。

## 搜索与分类

顶部搜索支持域名、子域名与备注。分类用于按项目、客户或环境分组。

添加分类：

1. 点击“添加分类”。
2. 输入分类名称。
3. 保存。
4. 在域名编辑中修改所属分类。

管理员可以通过 API 或页面修改、删除分类。删除分类不会删除域名，域名会回到未分类。

## 编辑域名

域名编辑支持：

- 分类。
- 备注。
- 隐藏域名。
- 允许单点登录。
- 到期提醒开关。
- 只读标记。

隐藏域名用于减少列表干扰。单点登录与跳转能力按部署环境使用。

## 到期时间

域名列表展示到期时间。点击“刷新到期时间”会通过 WHOIS 或 RDAP 查询。

- 查询结果会写回域名记录。
- 查询失败时保留原值，页面显示失败状态。
- 到期提醒使用该时间计算提醒节点。

## 批量操作

勾选多个域名后可以：

- 批量开启或关闭到期提醒。
- 批量删除本地域名记录。

批量删除默认只删除本地纳管记录，不会删除云端域名。执行前确认没有解析任务、CDN 联动或授权依赖。

## 收录与解析记录数

列表展示每个域名的记录数与只读状态。点击域名进入解析记录页。记录数来自云端实时查询或本地缓存，服务商接口异常时可能显示为空。

## 与 CDN 的联动

接入 CDN 加速域名时，系统会尝试匹配已纳管的域名，并自动添加 CNAME 解析。匹配不到时，需要先在域名列表导入对应根域名。

删除 CDN 域名时可以选择是否同时删除联动的 DNS 记录，详见 [CDN 域名](/cdn/domains)。

## 常见问题

### 导入后列表没有记录

点击域名进入记录页重新加载。确认账户凭证具备读取解析记录的权限，并确认域名已切换到对应服务商的 NS。

### 到期时间一直未查询

部分后缀的 WHOIS 服务不稳定。可以稍后重试，或手动编辑维护到期时间。

### 域名显示只读

只读来自普通用户的域名授权。管理员不受该限制。
