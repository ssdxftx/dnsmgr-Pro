# 批量与高级操作

## 文本批量导入

适合从旧系统迁移或一次创建多条记录。

格式：

```text
主机记录 记录值
www 203.0.113.10
@ 203.0.113.10
api cname.example.com
mail mx.example.com 10
```

注意事项：

- 每行一条记录。
- 主机记录与记录值之间用空格或制表符分隔。
- 自动识别类型时根据记录值判断 A、AAAA 与 CNAME。
- MX、SRV、CAA 等复杂类型建议手动添加或在导入页固定类型。
- 导入前确认没有重复记录。

## 全局记录搜索

域名列表顶部搜索支持域名、子域名与备注。记录页内部也提供筛选与搜索，便于在大域名中定位记录。

定位记录后可以直接编辑、启停或删除。

## 批量修改

勾选记录后使用“更多批量操作”：

- 批量修改记录值：适合切换源站 IP。
- 批量修改线路：适合调整多线路解析。
- 批量修改备注：适合批量标注项目或用途。
- 移动到分组：需要服务商支持分组能力。

批量修改会逐条调用云端接口。部分失败时页面会显示失败数量与原因，未失败的记录不受影响。

## 权重解析

权重解析只适用于阿里云。

1. 进入域名的“权重解析”。
2. 查看同一子域名的多条记录。
3. 点击“配置权重”。
4. 为每条记录填写权重。
5. 开启权重。

关闭权重后恢复普通解析。权重规则、线路与记录数量以阿里云控制台为准。

## 域名别名

域名别名只适用于 DNSPod。

1. 进入域名的“域名别名”。
2. 点击“添加别名”。
3. 输入别名域名，例如 `example.com`。
4. 保存。

别名共享主域名的解析记录。别名域名需要满足 DNSPod 的归属与验证要求。删除别名不会删除主域名记录。

## 解析日志

阿里云账户支持解析日志。日志展示：

- 操作时间。
- 主机记录。
- 记录 ID。
- 操作结果。

日志用于排查“谁在什么时候改了记录”。其他服务商请在云端控制台查看。

## 记录分组

部分服务商支持记录分组。分组用于批量移动和筛选，不改变解析行为。服务商不支持时页面不会显示分组入口。

## 操作建议

- 大批量修改前先导出或备份整站数据。
- 修改 A/CNAME 记录后，用记录检测确认生效。
- 与 CDN、证书、容灾相关的记录，修改前先检查联动任务。
- 删除记录前确认没有定时切换或容灾策略引用。
