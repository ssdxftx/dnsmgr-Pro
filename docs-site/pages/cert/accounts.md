# 证书账户

证书账户保存 ACME 或云厂商签发渠道的凭证。

## 添加账户

1. 打开“SSL 证书 → SSL 证书账户”。
2. 点击“添加账户”。
3. 选择证书服务商。
4. 填写账户名称与备注。
5. 按服务商要求填写邮箱、EAB、AccessKey、Secret 或其他参数。
6. 点击“保存并验证”。

## 常见渠道配置

| 渠道 | 关键参数 |
| --- | --- |
| Let's Encrypt | 邮箱，可选 EAB |
| ZeroSSL | 邮箱或 API Key，按页面要求 |
| Google SSL | 邮箱与 EAB |
| LiteSSL | 邮箱与 API 凭证 |
| 腾讯云免费 SSL | SecretId、SecretKey |
| 阿里云免费 SSL | AccessKey ID、AccessKey Secret |
| UCloud 免费 SSL | 公钥、私钥 |
| 自定义 ACME | ACME 目录地址、邮箱、EAB |

具体字段以页面为准。账户验证会检查凭证格式与接口连通性。

## 账户用途

- 申请单域名或泛域名证书。
- 自动续签。
- 为 ESA 站点申请通配符证书。
- 为 EdgeOne 或 ESA 上传证书。

## 默认 Let's Encrypt

当没有可用证书提供商时，CDN 证书联动可以使用默认 Let's Encrypt 签发精确子域名证书。系统设置中需要配置可用的联系邮箱。

## 编辑与删除

编辑可以修改名称、备注与凭证。删除前确认没有进行中的订单或自动任务引用该账户。

删除账户不会删除已签发的证书文件，但后续续签会失败。

## 私有账户

普通用户可以在凭证保险库中创建私有证书账户。私有账户只对该用户可见。

## 常见问题

### ACME 账户注册失败

检查邮箱格式、ACME 目录地址、EAB Key ID 与 HMAC Key 是否匹配，以及服务器时间是否准确。

### 云厂商验证失败

检查 AccessKey 权限、产品是否开通、账户是否实名或欠费。

### 续签时提示账户不可用

重新验证账户凭证，或更换签发渠道。Let's Encrypt 有速率限制，频繁失败会被暂时限制。
