# 自动部署

自动部署把证书订单中的证书推送到目标平台。支持面板、WAF、CDN、云厂商、服务器与存储。

## 部署目标

常见类别：

- 面板：宝塔、1Panel、AMH、CloudPanel、DirectAdmin、小皮面板、耗子面板、AcePanel、MW。
- 系统与虚拟化：群晖、飞牛 OS、Proxmox VE。
- 容器与集群：K8S。
- WAF：雷池、堡塔云 WAF、南墙、AxisNow。
- CDN：Cloudflare、Cdnfly、LeCDN、GoEdge、Cachefly、阿里云、腾讯云、华为云、UCloud、七牛云、多吉云、又拍云、百度云、金山云、火山引擎、西部数码、网宿、白山云、天翼云、雨云、uniCloud、AWS、Gcore。
- 服务器与存储：SSH、FTP、S3、本地目录。

具体字段随部署类型不同。

## 添加部署账户

1. 打开“SSL 证书 → 自动部署账户”。
2. 点击“添加账户”。
3. 选择部署类型。
4. 填写名称与备注。
5. 填写目标平台地址、账号、密钥或 Token。
6. 保存并验证。

SSH 目标建议使用专用密钥，限制登录来源与命令权限。FTP 与自签名 K8S 默认校验证书，确需关闭时由服务端环境变量控制。

## 创建部署任务

1. 打开“SSL 证书 → 自动部署任务”。
2. 点击“添加任务”。
3. 选择部署账户。
4. 选择已签发的证书订单。
5. 填写任务备注。
6. 保存。
7. 点击“执行部署”。

任务列表展示部署类型、绑定域名、启用状态、最后部署时间与状态。

## 自动触发

当证书订单续签或重新签发成功后，启用的部署任务会自动执行。执行时间受“自动续签设置”的运行时段限制。

## 手动操作

| 操作 | 说明 |
| --- | --- |
| 执行部署 | 立即推送证书 |
| 重置 | 清除部署状态，允许重新部署 |
| 启停 | 控制是否参与自动部署 |
| 删除 | 删除本地任务 |
| 查看日志 | 查看每步结果与错误 |

批量执行会创建异步任务，可在任务中心查看进度。

## 自定义命令

部署任务默认禁止执行自定义命令。确需执行时，服务端必须同时配置：

```bash
DNSMGR_ALLOW_DEPLOY_CMD=1
DNSMGR_DEPLOY_CMD_ALLOWLIST=systemctl reload nginx,docker restart
```

白名单按命令前缀匹配，命令不经过 shell，且拒绝包含 shell 控制符的内容。

## 部署失败排查

1. 确认证书订单已签发且未过期。
2. 确认部署账户凭证有效。
3. 检查目标平台地址、端口、协议与证书校验。
4. 查看部署日志中的 HTTP 状态或 SSH 输出。
5. 确认目标路径可写、服务有权限重载。
6. 对 CDN 目标确认域名归属与证书配额。

## 安全建议

- 每个目标使用独立凭证。
- 部署账户只授予证书上传与重载所需权限。
- 定期轮换 SSH 密钥与 API Token。
- 不要把私钥写入日志或工单。
