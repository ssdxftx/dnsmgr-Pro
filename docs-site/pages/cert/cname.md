# CNAME 代理

CNAME 代理用于把证书 DNS 验证委托到集中的验证服务。适合域名 DNS 不在本项目纳管账户中的情况。

## 工作方式

1. 在 CNAME 代理页面添加域名与别名记录值。
2. 到域名服务商处把 `_acme-challenge` 指向代理目标。
3. 回到页面点击“检测”。
4. 验证生效后，证书订单可以通过代理完成 DNS-01。

## 添加记录

1. 打开“SSL 证书 → CNAME 代理”。
2. 点击“添加 CNAME”。
3. 选择域名。
4. 填写别名记录值，例如 `acme.example.com`。
5. 保存。
6. 在域名服务商处添加 CNAME。
7. 点击“检测”。

状态分为已生效与待验证。检测会查询 CNAME 是否已解析到目标。

## 在订单中使用

创建证书订单时选择 CNAME 代理验证方式，并选择已生效的代理记录。订单处理时会向代理服务写入 TXT 值。

## 删除

删除代理记录不会删除域名服务商处的 CNAME。需要同时到服务商处清理。

## 常见问题

### 一直待验证

- CNAME 记录尚未生效。
- 记录名写错，应为 `_acme-challenge`。
- 目标值多了协议或路径。
- TTL 未过期。

### 订单仍验证失败

确认代理记录属于当前域名，且订单绑定的域名与代理域名匹配。查看订单日志中的具体错误。

### 多个域名

每个需要验证的域名单独添加一条代理记录。泛域名按 ACME 要求处理。
