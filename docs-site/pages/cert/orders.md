# 证书订单

证书订单记录一次证书申请或导入。订单列表展示类型、绑定域名、到期时间、状态与操作。

## 自动申请

1. 点击“申请证书”。
2. 选择“自动申请”。
3. 选择证书账户。
4. 选择密钥类型与密钥长度。
5. 每行填写一个绑定域名。
6. 提交。
7. 在订单行点击“处理”推进签发。

泛域名填写 `*.example.com`。泛域名通常需要 DNS-01 验证。多个域名会合并为同一张证书。

## DNS 验证

系统优先使用 DNS-01：

1. 在对应 DNS 账户中添加 `_acme-challenge` TXT 记录。
2. 等待记录生效。
3. 回到订单点击“处理”或“验证”。
4. 查看处理日志。

如果域名不在本项目纳管的 DNS 账户中，可以使用 [CNAME 代理](/cert/cname)。

## 手动导入

1. 点击“申请证书”。
2. 选择“手动导入”。
3. 填写证书内容与私钥内容。
4. 填写绑定域名。
5. 保存。

手动导入的证书不会自动续签，但仍可以被部署任务引用。

## 订单操作

| 操作 | 说明 |
| --- | --- |
| 验证 | 检查 DNS 记录或域名归属 |
| 处理 | 推进签发流程 |
| 重置 | 清空申请进度并重新开始 |
| 详情 | 查看证书、私钥、签发时间与到期时间 |
| 日志 | 查看每一步处理结果 |
| 吊销 | 吊销已签发证书 |
| 删除 | 删除本地订单 |

## 证书详情与导出

详情页可以：

- 复制证书 PEM。
- 复制私钥。
- 下载证书。
- 下载私钥。
- 下载 PFX。

PFX 导出需要 `openssl`。PFX 密码按页面提示处理。私钥属于敏感信息，避免通过聊天或公开仓库传输。

## 自动续签

订单行可以开启或关闭自动续期。开启后按“自动续签设置”中的到期前天数执行。续签成功会更新证书，并触发引用该订单的部署任务。

## 批量处理

管理员可以批量推进证书订单。批量处理会创建异步任务，返回 `job_id`，可在 `/api/jobs` 或页面任务中查看进度。

## 到期提醒

列表显示剩余天数。即将到期的证书会突出显示。到期前请确认续签成功并完成部署。

## 常见问题

### 一直等待验证

检查 `_acme-challenge` 记录是否添加到正确域名、值是否完整、TTL 是否过长。用公共 DNS 查询确认生效。

### 签发失败

查看处理日志中的 ACME 错误。常见原因包括域名不可达、验证记录错误、速率限制与账户凭证失效。

### PFX 下载失败

确认服务器安装了 `openssl`。容器镜像已内置。

### 删除订单后部署任务失败

部署任务引用的订单已不存在。先删除或重新绑定部署任务。
