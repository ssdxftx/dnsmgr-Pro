# SSL 证书与部署

证书模块负责申请、续签、导入、导出、吊销与自动部署。

## 支持的签发渠道

Let's Encrypt、ZeroSSL、Google SSL、LiteSSL、腾讯云免费 SSL、阿里云免费 SSL、UCloud 免费 SSL、自定义 ACME。

## 使用流程

1. 在“SSL 证书账户”添签发渠道。
2. 在“证书订单”申请证书或手动导入。
3. 选择 DNS-01 验证方式并完成验证。
4. 签发后下载证书、私钥或 PFX。
5. 在“自动部署账户”添加目标平台。
6. 在“自动部署任务”绑定证书与目标。
7. 在“自动续签设置”配置续签天数、运行时段与通知。

## 自动续签与部署

证书订单开启自动续签后，系统在到期前按设置的天数续签。续签成功后，引用该订单的部署任务会自动执行。

自动续签与自动部署都受“运行时段”限制。支持跨天，例如 `22 至 6`。
