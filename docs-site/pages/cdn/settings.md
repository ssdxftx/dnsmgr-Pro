# 加速域名设置

在“CDN 域名”列表点击“配置”，进入加速域名设置。页面包含回源、缓存、HTTPS 与访问控制。

## 域名状态

顶部展示启用状态与 CNAME。可以启用或停用加速。停用后云端停止加速，但域名与配置保留。

## 回源配置

| 字段 | 说明 |
| --- | --- |
| 源站地址 | IP 或域名，多个源站按分号或厂商格式填写 |
| 源站类型 | IP 源站或域名源站 |
| 回源 Host | 留空使用默认值；对象存储常需填写绑定域名 |
| 回源协议 | HTTP、HTTPS 或协议跟随 |
| 回源端口 | HTTP/HTTPS 对应端口 |

保存后立即下发到云端。修改源站会影响所有回源请求，建议在低峰期操作。

## 缓存规则

缓存规则按匹配方式设置 TTL：

- `*`：全部文件。
- `.jpg`：按后缀。
- `/dir/`：按目录。
- `/a.png`：按具体路径。

TTL 单位为秒：

- `0`：不缓存。
- 大于 `0`：缓存对应秒数。

点击“添加规则”可以设置多条。规则顺序与厂商模型有关，冲突时以云端实际生效规则为准。部分厂商规则生效需要几分钟。

## HTTPS

可以开启 HTTPS 与强制跳转 HTTPS。

- 关闭 HTTPS 会停止强制跳转。
- 证书由厂商分配，或在云端配置。
- 使用项目申请证书时，证书上传与绑定由自动部署任务完成。

修改 HTTPS 前确认证书已就绪，避免站点不可访问。

## 访问控制

### 防盗链 Referer

支持关闭、白名单与黑名单。输入域名或空值规则，例如 `*.example.com`。

### IP 黑白名单

支持单个 IP 与 CIDR，例如 `203.0.113.10`、`10.0.0.0/8`。按厂商能力选择白名单或黑名单。

### UA 黑名单

填写需要拦截的 User-Agent。留空表示关闭。

保存访问控制后立即下发。配置错误可能误拦截正常用户，建议先在测试域名验证。

## 站点级设置

EdgeOne 与 ESA 的站点级配置在“CDN 站点设置”中完成，包括全局缓存、TLS、回源 HTTP/2、智能路由、压缩、IPv6、上传大小与安全策略。详见 [站点设置](/cdn/zones)。

## 与证书联动

域名设置中的证书方式决定是否由本项目自动部署证书。切换证书方式后，可以在“证书管理”查看部署进度。删除联动域名时，系统会先吊销联动证书。

## 验证

```bash
# 查看 CNAME
dig +short www.example.com CNAME

# 查看 HTTPS 与缓存头
curl -sI https://www.example.com/ | grep -iE 'HTTP/|cache-control|server'
```

修改后如未生效，先刷新 CDN 缓存并等待 TTL 过期。
