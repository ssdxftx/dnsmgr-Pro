# CDN 域名与接入

“CDN 域名”管理各厂商的加速域名。接入完成后，页面展示 CNAME、状态、证书方式、线路与源站。

## 接入加速域名

点击“接入域名”，按步骤填写。

### 1. 账户与站点

1. 选择 CDN 账户。
2. 选择服务区域：中国大陆、中国大陆以外或全球。
3. 站点型厂商需要选择站点。

### 2. 加速域名

1. 填写子域名，例如 `www`。
2. 系统自动拼接为 `www.example.com`。
3. 系统尝试匹配已纳管的 DNS 域名，用于自动添加 CNAME。

如果提示“未匹配到已添加的域名”，先到“域名管理”导入根域名。

### 3. 回源配置

| 字段 | 说明 |
| --- | --- |
| 源站地址 | IP 或域名，多个源站按厂商要求分隔 |
| 源站类型 | IP 源站或域名源站 |
| 回源协议 | HTTP、HTTPS 或协议跟随 |
| 回源端口 | 按源站实际端口填写 |
| 回源 Host | 可使用加速域名、源站域名或自定义 |

回源 Host 会影响源站虚拟主机匹配。使用对象存储或按域名分站的源站时尤其要确认。

### 4. 证书设置

可选：

- 平台免费证书。
- 项目申请证书并上传绑定。
- 暂不配置证书。
- 什么都不做，使用站点原有配置。

项目申请证书时，系统按站点申请通配符证书，签发后自动上传并创建部署任务。后续续签自动更新。

### 5. 加速场景模板

站点型厂商可以选择预制加速场景模板。模板会为本次域名创建一条规则，并把域名匹配自动填入。也可以选择“不使用模板”，直接使用站点原有配置。

模板应用失败不会回滚域名创建，页面会提示失败原因，可以到站点规则页手动创建。

## CNAME 与生效

接入后页面显示 CNAME 地址。请到 DNS 服务商添加 CNAME 记录，或让系统自动添加。生效后刷新状态。

部分厂商需要归属验证。EdgeOne 与 ESA 站点页会展示验证方式，DNS 托管接入可以自动验证。

## 同步云端域名

点击“同步云端”可以：

1. 拉取厂商侧已有加速域名。
2. 检查是否已在本地接入。
3. 选择需要纳管的域名。
4. 开始同步。

同步不会删除本地记录。重复域名会被跳过或提示已存在。

## 证书管理

域名行的“配置”可以：

- 查看云端当前证书。
- 刷新云端证书状态。
- 切换证书方式。
- 查看 CDN 证书部署进度。
- 立即检查并部署。
- 查看执行日志。

本地记录与云端证书不一致时，以云端为准。切换证书方式前先确认 HTTPS 状态。

## 启停与删除

启用或停用加速域名会影响云端加速状态。

删除域名时可选：

- 同时删除云端加速域名。删除后云端资源不可恢复。
- 同时删除联动的 DNS 解析记录。
- 若域名由本项目管理证书，删除时会先吊销联动证书，吊销成功后再删除。

删除云端资源需要二次确认。操作前请确认没有业务流量或已切换流量。

## 常见问题

### 域名已存在

加速域名可能已在本地或云端接入。页面会提示站点信息。先同步云端或检查其他账户。

### CNAME 不生效

检查 DNS 记录是否添加、是否与厂商给出的目标一致、TTL 是否过期，以及域名是否被其他 CDN 占用。

### HTTPS 无法开启

确认证书已签发并绑定，域名归属验证已通过。平台免费证书需要等待厂商签发。

### 删除失败

云端资源可能仍有关联规则、证书或其他配置。先到厂商控制台清理关联资源。
