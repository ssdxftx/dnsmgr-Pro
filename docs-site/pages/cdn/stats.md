# 数据统计

数据统计展示 CDN 的流量、带宽、请求、回源与缓存命中情况。

## 支持厂商

- 腾讯云 CDN
- 腾讯云 EdgeOne
- 阿里云 CDN
- 阿里云 ESA

其他厂商以各自控制台为准。

## 查询范围

支持：

- 近 24 小时
- 今天
- 近 7 天
- 近 30 天
- 自定义时间范围

可以按 CDN 账户与加速域名筛选。ESA 可以单独选择站点。

## 指标

常用指标：

| 指标 | 说明 |
| --- | --- |
| 加速流量 | 客户端访问产生的流量 |
| 回源流量 | 回源到源站的流量 |
| 峰值带宽 | 查询区间内的带宽峰值 |
| 日均带宽 | 按天平均的带宽 |
| 请求总数 | 客户端请求数量 |
| 缓存命中率 | 命中缓存的流量或请求占比 |
| 状态码分布 | 2xx、3xx、4xx、5xx 等 |

详情页提供流量趋势、带宽趋势、请求趋势、状态码分布以及 Top 域名、URL、Referer、国家/地区、省份、客户端 IP 等排行。

## 分析与日志

“分析与日志”标签可以查看厂商提供的明细能力。ESA 站点可以选择站点后查询。

## 统计缓存

管理员可以在“系统设置 → 统计缓存”中开启缓存：

1. 系统按厂商数据粒度定时拉取。
2. 近 30 天按天保存，近 48 小时按小时保存。
3. 打开统计页时优先展示缓存数据。
4. 可设置刷新间隔、立即刷新或清空缓存。

缓存会持续消耗服务器资源。仅为需要的用户开启“统计缓存”权限。

## 部分失败

多个厂商同时查询时，如果部分接口失败，页面会展示失败来源，其他厂商数据正常显示。可以单独重试。

## 数据延迟

上游统计通常有几分钟延迟。页面会显示数据截止时间与延迟提示。

## 常见问题

### 没有数据

确认所选时间范围、账户与域名正确，且该时段有真实流量。新接入域名可能尚未产生统计。

### 命中率低

检查缓存规则、TTL、查询参数与 Cookie 是否导致无法缓存。

### 数据与厂商控制台不一致

不同接口的统计口径、时间粒度与延迟可能不同。以厂商控制台账单与最终数据为准。
