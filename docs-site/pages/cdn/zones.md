# CDN 站点设置

“CDN 站点设置”以站点为维度管理 EdgeOne、ESA 与 Cloudflare 的站点级能力。只有接入到站点类型的加速域名后才会显示站点。

## 站点列表

列表展示：

- CDN 类型。
- 站点名称。
- 站点 ID。
- 状态。
- 关联加速域名数量。
- 操作入口。

可以按账户筛选，也可以查看全部本地已接入站点。

## 站点属性

EdgeOne 站点可以在概览页修改接入方式、加速区域、同名站点标识与自定义 NS。修改接入方式或区域可能影响现有流量，保存前先确认站点状态与套餐限制。

## 站点配置导入导出

EdgeOne 支持导出站点配置并在其他站点导入：

1. 在概览页点击“导出配置”，下载 JSON 配置文件。
2. 点击“导入配置”，粘贴导出内容并提交。
3. 导入任务会返回任务 ID，页面会自动查询执行结果。

当前支持导入七层加速配置与 Web 安全配置。加速域名与源站配置可以导出，但腾讯云暂不支持通过该接口导入。

## 共享 CNAME 与别称域名

CNAME 接入的 EdgeOne 站点可以创建共享 CNAME，并把多个加速域名绑定到同一条 CNAME，减少 DNS 解析配置。共享 CNAME 功能需要企业版套餐并处于内测范围。

别称域名用于把一个域名指向站点内的目标域名，可配置证书并独立启停。该功能同样仅企业版支持。

## 边缘函数与 KV

边缘函数页签可以创建、修改、删除函数，并管理触发规则、运行环境、代码副本与组件绑定。函数内容使用 JavaScript，创建与修改通过官方结构 JSON 提交。

运行环境可以维护环境变量；代码副本用于在不影响生产代码的情况下验证新版本；组件绑定当前支持把 EdgeKV 命名空间绑定为函数变量。

EdgeKV 以命名空间隔离数据。可以创建、修改、删除命名空间，查看键列表，读取、写入、删除键值。键值支持设置 TTL，写入后按 TTL 自动过期。

## 版本管理

版本管理仅支持标准版与企业版站点。站点页的“版本管理”标签可以查询环境信息、配置组版本、版本详情与发布历史，并创建或发布版本。发布前先确认目标环境与版本 ID，发布记录会保留在历史中。

## API 防护

API 防护以 API 服务与 API 资源组织。API 服务定义基础路径，API 资源定义具体路径、请求方法、关联服务与请求约束。两者都使用官方结构 JSON 管理，适合对业务 API 做精细化防护。

## 站点自定义变量

规则引擎可以使用站点级自定义变量。在“规则引擎”页加载与保存变量 JSON，变量名使用 `user.zone.` 前缀。保存时会覆盖对应变量列表；清空列表即删除变量。

## 站点全局配置

站点设置作用于站点下所有加速域名：

| 配置 | 说明 |
| --- | --- |
| 强制 HTTPS 跳转 | 将 HTTP 请求跳转到 HTTPS |
| 含子域 | 规则是否包含子域名 |
| TLS 版本 | 允许的 TLS 最低版本 |
| 回源 HTTP/2 | 回源是否使用 HTTP/2 |
| 超时 | 回源超时时间 |
| 节点缓存模式 | 遵循源站、自定义时间或不缓存 |
| 缓存预刷新 | 缓存过期前提前回源 |
| 离线缓存 | 源站不可用时使用缓存 |
| 智能路由 | 按网络质量选择回源线路 |
| 内容压缩 | 开启压缩 |
| IPv6 访问 | 允许 IPv6 客户端 |
| 客户端 IP 头 | 自定义真实 IP 请求头 |
| 客户端 IP 地区头 | 传递国家或地区信息 |
| 上传大小限制 | 最大请求体 |
| 中国大陆加速 | 是否启用中国大陆节点 |

保存后会下发到云端。站点级配置影响范围大，修改前先在测试站点验证。

## 源站组与负载均衡

站点型厂商支持源站组：

1. 新建源站组。
2. 添加多个源站与权重。
3. 配置健康检查。
4. 在规则或域名中引用源站组。

负载均衡可以按权重、优先级或健康状态选择源站。源站组与负载均衡的可用字段随厂商不同。EdgeOne 负载均衡列表提供“健康”入口，可查看各源站组与源站的实时健康状态。

## 规则引擎

规则引擎支持按条件匹配请求并执行动作。常见能力：

- 回源配置。
- 重定向。
- URL 重写。
- 请求头与响应头转换。
- 缓存设置。
- 防火墙。
- 速率限制。
- 四层代理规则。

规则有优先级。新增规则前先确认匹配条件与动作范围，避免覆盖站点全局配置。

EdgeOne 自定义响应页面可以在规则引擎中引用，支持 HTML、JSON、纯文本、XML、CSS 与 JavaScript 内容。页面内容有大小限制，保存前确认内容类型与内容匹配。

安全扩展还支持 JavaScript 注入规则与客户端认证选项。两者使用官方结构 JSON 管理，适合接入客户端 SDK、人机校验或自定义注入逻辑。

## 安全能力

按厂商支持：

- 安全 IP 组。
- DDoS 防护。
- WAF。
- 安全策略模板绑定与解绑。
- 访问控制。
- 速率限制。
- 源站防护（ESA）。
- 开发模式（ESA）。

安全策略可能影响正常流量。开启拦截前建议先观察或使用告警模式。

EdgeOne 源站防护开启后，回源会使用 EdgeOne 指定的回源 IP 网段。页面可以读取源站防护详情、修改控制域或回源实例，并确认最新回源 IP 网段。变更前先把新网段同步到源站防火墙，避免回源失败。

## 四层代理

站点型厂商支持四层代理与四层规则：

- 新建四层代理。
- 启用或停用四层代理。
- 配置监听端口与源站。
- 添加、启用、停用或删除四层规则。
- 管理转发策略。

四层代理不经过 HTTP 规则引擎，配置前确认协议与端口。

## 配额与任务

站点页可以查看内容与刷新配额、刷新与预热任务。任务失败时按厂商错误调整。

EdgeOne 还可以配置预热回源限速，按加速域名与区域限制预热回源带宽。该功能处于内测阶段，使用前确认账号已开通白名单。

“任务与统计”页提供 DDoS 攻击事件、DDoS Top、四层流量时序与 IP 归属诊断。查询结果以 JSON 展示，适合排查攻击与节点归属。

实时日志投递可以推送到 EdgeOne 日志分析、CLS、S3 兼容存储或自定义 HTTP 服务。任务创建与修改使用官方参数 JSON，支持启停与删除。离线日志按站点与时间范围获取下载链接，七层与四层分开查询。

内容标识符按账号管理，需要绑定企业版套餐，创建后可在规则引擎中引用。

## 多通道安全网关

多通道安全网关用于把客户端流量通过多条线路回源，适合实时互动、对战游戏、金融交易与视频会议等对网络质量敏感的业务。

站点页的“多通道网关”标签支持：

- 查询云上网关与自有网关，查看网关类型、端口、地址、地域与在线状态。
- 创建、修改、启停与删除网关。
- 查看网关线路，创建、修改与删除自定义线路；直连线路由系统维护。
- 查看与确认回源 IP 网段。回源网段更新后，先把新网段同步到源站防火墙，再在页面确认。
- 管理站点级接入密钥，支持创建、更新与刷新。刷新后旧密钥立即失效，客户端 SDK 需要同步更新。

自有网关需要先把网关 IP 录入腾讯云多通道安全加速网关系统，再在页面创建。云上网关需要选择可用地域，地域列表可以直接在页面查询。

## 边缘推理

边缘推理把容器化模型部署到 EdgeOne 边缘节点，当前仅企业版套餐支持，并需要申请白名单。

“边缘推理”标签支持：

- 创建、修改、停止、启动与删除推理服务。
- 查看部署记录与部署日志。
- 查询 CPU、GPU、内存与实例数监控数据。
- 创建与删除推理 API Token。
- 创建、启停与删除推理域名，配置请求鉴权开关。
- 查询可用硬件规格。

创建服务需要填写监听端口、容器镜像、资源配置与请求路径。容器与资源配置字段较多，页面使用官方参数 JSON 提交。Token 内容只在创建时返回一次，需要立即保存。

## 媒体处理

“媒体处理”标签管理即时转码模板。EdgeOne 提供系统预置模板，也可以创建自定义模板，配置编码格式、码率、分辨率、帧率、填充模式与音频参数。

即时转码不需要提前转码视频，客户端按模板地址访问时由边缘节点实时处理。地址格式：

```text
https://example.com/video.mp4/.edgeone-video/template={模板 ID}/media.m3u8
```

MP4 输出把后缀改为 `media.mp4`。模板 ID 在创建后返回，也可以在模板列表复制。删除模板前确认没有业务仍在使用对应地址。

## 套餐与计费

“套餐计费”标签集中管理 EdgeOne 套餐与用量：

- 查看账号下的套餐实例、状态、到期时间与绑定站点。
- 查询当前账号可购买的套餐类型与价格。
- 购买套餐，支持个人版、基础版、标准版与企业版。
- 套餐续费、升级、增购配额与销毁。
- 修改预付费套餐的自动续费开关。
- 按站点、域名、四层代理实例或计费大区查询流量、带宽、请求数、边缘函数与媒体处理用量。

计费查询的时间范围最长 31 天，时间粒度为 5 分钟、1 小时或 1 天。套餐购买与销毁会产生订单或影响现有站点，执行前确认账号余额与套餐绑定关系。

## 站点生命周期

支持：

- 创建站点并选择套餐。
- 为未激活站点绑定套餐。
- 修改站点。
- 检测站点。
- 验证归属。
- 暂停站点。
- 删除站点。

删除站点会影响其下所有加速域名。执行前先迁移流量。

## 常见问题

### 站点列表为空

确认账户有站点资源与读取权限，且已接入至少一个站点类型的加速域名。

### 规则不生效

检查规则优先级、匹配条件、开关状态与缓存。CDN 规则变更通常需要短暂生效时间。

### 站点验证失败

按页面提示添加 TXT 或 NS 记录。使用 DNS 托管接入时，系统可以自动添加验证记录。
