# CDN 账户

CDN 账户保存厂商授权信息。一个账户可以接入多个加速域名，也可以管理厂商侧的站点。

## 添加账户

1. 打开“CDN 管理 → CDN 账户”。
2. 点击“添加账户”。
3. 选择服务商。
4. 填写账户名称与备注。
5. 按厂商要求填写 SecretId、SecretKey、API Token、AccessKey、用户名密码等凭证。
6. 点击“保存并验证”。

## 凭证权限

不同厂商需要不同权限：

- CDN 域名接入、查询、启停、删除。
- 缓存刷新与预热。
- 证书查询、上传与绑定。
- 统计数据读取。
- 站点、规则、源站组、负载均衡、安全与四层代理。

权限不足时，账户可以保存但部分功能会返回云端错误。按实际使用的模块授予最小权限。

## 编辑与删除

编辑可以修改名称、备注与凭证。删除前确认没有加速域名、站点、规则或自动任务依赖。

删除账户只删除本地凭证。云端资源是否保留取决于删除账户时是否同时清理，页面不会自动删除云端资源。

## 站点型账户

EdgeOne 与 ESA 的站点级能力需要账户具备站点读取与管理权限。接入后“CDN 站点设置”会展示站点列表。

Cloudflare 不在此处添加。Cloudflare 的 DNS 账户可以直接用于规则引擎，凭证不足时可在站点页配置专用加密凭证。

## 私有账户

普通用户可以在凭证保险库中创建私有 CDN 账户。私有账户只对该用户可见，管理员无法查看明文。管理员的共享账户可以授权给多个用户。

## 常见问题

### 验证失败

检查凭证是否启用、是否绑定 IP 白名单、是否有 CDN 产品权限、账户是否欠费。

### 能查询域名但不能刷新缓存

缓存刷新需要额外权限。为凭证补充刷新与预热权限后重新保存。

### 站点列表为空

确认账户下有站点资源，且凭证具备站点读取权限。部分厂商要求指定区域或项目。
