# 偏好设置与安全

用户菜单包含偏好设置、安全设置、语言与退出登录。

## 偏好设置

### 界面语言

支持简体中文与 English。首次访问根据浏览器语言选择，登录后与账号同步保存。

### API 密钥

API 密钥用于脚本、CI/CD、监控系统远程调用。密钥只在创建或轮换时显示一次。

创建步骤：

1. 点击“创建 API 密钥”。
2. 填写名称，例如“CI 部署”或“监控脚本”。
3. 选择权限范围。默认 `*` 表示全部权限；建议按模块设置最小权限，例如 `dns:read`、`cdn:write`。
4. 设置过期时间。留空表示长期有效。
5. 填写 IP 白名单，每行一个 IP 或 CIDR。留空表示不限制。
6. 输入登录密码确认。
7. 保存后立即复制完整密钥。

密钥列表展示前缀、名称、作用域、最近使用时间、状态与操作。

支持：

- 轮换：旧密钥立即失效，生成新密钥。
- 吊销：单把密钥立即失效。
- 全部吊销：当前用户全部密钥立即失效。
- 停用旧版密钥：停用 `user.apikey` 单密钥。

轮换与吊销需要再次输入登录密码。吊销后使用该密钥的脚本会立即失败。

### 作用域

格式：

```text
模块:read
模块:write
模块:*
*
```

模块包括 `dns`、`cdn`、`cert`、`deploy`、`cloudflare`、`backup`、`monitor`、`schedule`、`optimize`、`dnscheck`、`expire`、`vault`、`users`、`system`、`audit`、`jobs`、`events`、`apikeys`、`general`。

作用域只限制模块，域名授权与管理员等级仍会叠加校验。

### IP 白名单

支持 IPv4、IPv6 与 CIDR，例如：

```text
203.0.113.10
10.0.0.0/8
2001:db8::/32
```

来自非白名单地址的请求会被拒绝。使用动态出口 IP 的 CI 环境要预留更新机制。

## 安全设置 TOTP

1. 打开用户菜单“安全设置（TOTP）”。
2. 点击“开启两步验证”。
3. 使用 Google Authenticator、Microsoft Authenticator 等扫描二维码，或手动输入密钥。
4. 输入 APP 显示的 6 位动态口令。
5. 输入登录密码确认。
6. 完成绑定。

开启后登录需要先输入用户名密码，再输入动态口令。

关闭 TOTP 需要输入登录密码。关闭后登录只校验密码。

## 主题

浅色与深色主题在侧边栏底部切换。主题偏好保存在浏览器本地。

## 语言切换

用户菜单“语言”可以即时切换。带参文案与表格列会随语言刷新。

## 安全建议

- 管理员必须开启 TOTP。
- API Key 使用最小作用域与到期时间。
- 为自动化单独创建密钥，不共用个人会话。
- 定期轮换密钥。
- 发现泄露立即吊销并检查审计日志。
