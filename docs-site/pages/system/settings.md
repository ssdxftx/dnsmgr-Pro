# 系统设置

“系统设置”集中管理通知、登录、注册、公告、代理、计划任务、旧版接口兼容与统计缓存。

## 通知设置

通知通道的详细配置见 [通知设置](/system/notifications)。本页提供邮件、WxPusher、Telegram、QQ 机器人、群机器人与自定义 Webhook 的入口与测试按钮。

## 登录设置

可以开启图形验证码。开启后登录页会要求输入验证码，降低自动化撞库风险。

登录、TOTP、注册、验证码与安装接口默认按 IP 限流。可用 `DNSMGR_RATE_LIMIT=0` 关闭。

## 注册设置

可以开启自助注册并选择方式：

### 邮箱验证码

需要配置可用的邮件发信。用户填写邮箱，获取验证码后注册。

### 注册码

管理员生成注册码。生成时可以设置：

- 数量。
- 有效期天数，`0` 表示永久。
- 可用次数，`0` 表示不限。
- 备注。

注册码列表展示状态、有效期与已使用次数。可以启用、停用或删除。

### 关闭注册

关闭后只能由管理员在用户管理中创建账号。

## 公告管理

公告会在用户登录后以弹窗展示。支持：

- 标题与内容。
- 类型：普通、成功、提醒、重要。
- 排序。
- 开始时间与结束时间。
- 启用状态。

开始时间留空表示立即生效，结束时间留空表示永久有效。删除公告不可恢复。

## 代理设置

系统代理用于需要访问外网的模块，例如 Telegram、Cloudflare、证书、部署与备份。

填写：

- 代理协议：HTTP、HTTPS 或 SOCKS。
- 代理 IP 与端口。
- 代理账号与密码，没有则留空。

保存后点击“测试连通性”。代理只应指向可信出口。允许代理解析本地无法解析的域名由 `DNSMGR_PROXY_ALLOW_UNRESOLVED` 控制。

## 计划任务

系统内置调度器，随服务启动自动运行。页面会说明不需要额外 cron。

为兼容旧版，页面提供：

- 外部触发地址。
- 访问密钥。
- 带 `X-Cron-Key` 请求头的触发命令。

外部触发只建议在迁移或特殊场景使用。密钥属于敏感信息，请通过 `X-Cron-Key` 请求头传递，避免放入 URL 查询参数。

## 旧版接口兼容

默认关闭。开启后提供旧版彩虹 DNS 的表单签名 API、域名快捷登录与 `/cron?key=` 触发地址，便于迁移旧客户端。

兼容层使用用户表中的旧版 `apikey` 和 MD5 签名，安全性低于新版 `X-API-Key`。目标用户需要开启 API 权限并保留旧版密钥。迁移完成后建议关闭并轮换密钥。

详细端点与认证方式见 [旧版彩虹 DNS API 兼容](/api/legacy)。

## 统计缓存

开启后系统按厂商数据粒度定时拉取 CDN 统计：

- 近 30 天按天。
- 近 48 小时按小时。

可以设置刷新间隔、立即刷新与清空缓存。清空会删除当前服务器上的全部统计缓存。

统计缓存会持续消耗资源。只为需要的用户开启查看权限。

## 安全确认

保存安全相关设置时可能需要输入登录密码。API 调用可以先用 `/api/auth/reauth` 换取 `X-Reauth-Token`。

## 环境变量

部分系统行为由服务端环境变量控制，例如：

- `DNSMGR_TRUST_PROXY`
- `DNSMGR_ALLOWED_ORIGINS`
- `DNSMGR_HSTS`
- `DNSMGR_CDN_CACHE`
- `DNSMGR_RATE_LIMIT`
- `DNSMGR_API_KEY_RATE_LIMIT`
- `DNSMGR_BODY_LIMIT`
- `DNSMGR_BACKUP_KEY`
- `DNSMGR_ALLOW_DEPLOY_CMD`
- `DNSMGR_DEPLOY_CMD_ALLOWLIST`
- `DNSMGR_MONITOR_CONCURRENCY`

完整列表见仓库 `.env.example`。

## 关于与更新

“关于”页面展示：

- 前端与后端版本。
- 前端构建时间。
- 运行环境与启动时间。
- 运行时长。
- 开源协议与项目仓库。
- 当前版本与最新版本。

点击“检查更新”会对比仓库标签。发现新版本时展示更新说明与下载入口。

默认更新源为 `ssdxftx/dnsmgr-Pro`。私有仓库或限流场景可以配置 `DNSMGR_UPDATE_REPO` 与 `DNSMGR_UPDATE_TOKEN`。

## 设置建议

1. 修改安全设置前记录原值。
2. 通知、代理与统计缓存保存后都做一次验证。
3. 注册码设置有效期与使用次数。
4. 公告设置结束时间，避免长期弹窗。
5. 升级前检查“关于”页面版本与更新说明。
