# 通知设置

通知通道用于到期提醒、证书续签、部署失败、容灾切换、劫持检测与备份完成等事件。

## 邮件

支持三种发信模式：

| 模式 | 关键参数 |
| --- | --- |
| SMTP | SMTP 服务器、端口、邮箱账号、密码、发信邮箱 |
| 搜狐 Sendcloud | API 用户、API Key、发信邮箱 |
| 阿里云邮件推送 | AccessKey、发信地址、区域 |

填写“收信邮箱”可以统一接收系统通知。留空时默认使用发信邮箱。

保存后点击“发送测试邮件”验证。

## 微信公众号 WxPusher

填写用户 UID。保存后发送测试消息。

## Telegram 机器人

填写 Bot Token 与 Chat ID。可以：

- 使用代理。
- 设置自定义反代 URL。
- 指定 Topic。

Telegram 在部分网络环境不可直连，可以配置系统代理或反代。

## QQ 机器人

1. 打开 QQ 开放平台 `q.qq.com`，创建机器人。
2. 在“开发设置”获取 AppID 与 AppSecret。
3. 在“事件订阅与回调”选择 Webhook，填写本页回调地址。
4. 接收事件选择“C2C 消息事件”。
5. 保存设置。
6. 在 QQ 中向机器人发送绑定口令。
7. 页面显示“已绑定”后完成。

机器人无需上线认证即可用于通知。绑定状态与回调地址在页面展示。

## 群机器人 Webhook

支持企业微信、钉钉、飞书等群机器人。

填写 Webhook 地址。部分平台需要 `@` 手机号或 `@all`：

- 手机号按平台要求填写。
- 需要 `@` 全体时填写 `all`。

## 自定义 Webhook

可以设置：

- 请求方式。
- 自定义 Headers，每行一个 `HeaderName: HeaderValue`。
- 请求 Body。
- 内容格式：纯文本或 JSON。

自定义 Webhook 适合接入自有告警平台。保存后发送测试消息确认格式。

## 通知投递历史

管理员可以查看通知投递历史：

- 通道。
- 事件。
- 状态。
- 错误。
- 时间。

发送失败时先检查凭证、网络与平台限制。

## 测试建议

1. 每个启用的通道都发送一次测试。
2. 在到期提醒中执行一次批量发送。
3. 创建测试证书订单或容灾策略验证事件通知。
4. 检查通知历史中的失败记录。

## 安全

- Webhook 地址与 Token 属于敏感信息。
- 不要把通知凭证写入公开仓库。
- 定期轮换机器人 Token 与 SMTP 密码。
- 自定义 Webhook 只指向可信地址。
