# 操作日志

操作日志记录每一次写操作：谁、何时、改了哪个对象、结果如何、变更前后值是什么。

## 查询

支持按以下条件筛选：

- 时间范围，含自定义时间。
- 用户。
- 模块。
- 操作。
- 结果：成功或失败。
- 摘要、对象、IP 或用户名关键字。

页面展示今日操作、近 7 天失败与近 30 天活跃用户。

## 记录内容

每条记录包含：

- 基本信息：用户、模块、操作、摘要、对象、结果、时间。
- 请求信息：请求 ID、IP、User-Agent。
- 变更内容：字段、原值、新值。
- 原始参数：已脱敏。

没有字段变更时会显示“本次操作无字段变更”。

## 模块与动作

模块覆盖认证、域名、解析记录、账户、CDN、证书、用户、系统、Cloudflare、定时任务、监控、DNS 检测、优选 IP、预热、到期提醒、API Key、任务与事件等。

动作示例：

- 新增、修改、删除解析。
- 批量导入。
- 账户新增、修改、删除。
- CDN 域名接入、启停、证书联动。
- 证书申请、续签、吊销。
- 部署执行。
- 用户与系统设置变更。
- API Key 创建、轮换、吊销。

## 详情

点击“详情”查看完整变更。敏感字段已脱敏，不会显示明文密码或密钥。

## 导出

管理员可以导出审计日志：

- JSON。
- CSV。

导出会遵循当前筛选条件。结果超过 1 万条时会提示缩小时间范围。

## 保留策略

审计日志按系统设置中的保留天数清理。需要长期留存时，定期导出或接入外部日志系统。

## 审计的作用

- 追溯误操作。
- 排查权限问题。
- 复核自动化任务。
- 对接合规要求。
- 定位 API 调用来源。

## 常见问题

### 找不到某次操作

确认时间范围、模块与关键字。部分只读请求不会写入审计。

### 日志中没有明文密码

这是预期行为。敏感字段会脱敏，审计只保留变更字段与脱敏参数。

### 日志过多

缩短保留天数，或按时间范围导出后归档。
