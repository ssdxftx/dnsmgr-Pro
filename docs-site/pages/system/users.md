# 用户管理

管理员在“系统设置 → 用户管理”中创建用户、调整等级、分配域名权限与管理 API。

## 用户概览

页面展示用户总数、管理员数量、API 启用数量与状态分布。列表支持按 UID 或用户名搜索。

## 添加用户

1. 点击“添加用户”。
2. 填写用户名。
3. 设置密码，或点击“随机生成”。
4. 选择用户等级：普通用户或超级管理员。
5. 按需开启 API 接口。
6. 保存。

普通管理员由 `level >= 2` 决定，超级管理员使用 `is_super` 标记。系统保证恰好一个超级管理员。

## 编辑用户

可以修改：

- 用户名。
- 重置密码。
- 用户等级。
- API 接口开关。
- 统计缓存权限。
- 子域名授权。
- 封禁或恢复状态。

重置密码留空表示不修改。

## API 接口

开启 API 后可以生成或填写旧版 API Key。旧版单密钥仍可用，但建议停用并改用支持作用域、有效期与 IP 白名单的新 API Key。

新 API Key 在“偏好设置”中由用户自行创建。管理员可以通过 `/api/api-keys?uid=...` 查看指定用户的密钥列表。

## 统计缓存

为普通用户开启“统计缓存”后，该用户可以查看 CDN 数据统计。前提是管理员已在系统设置中开启统计缓存。

## 子域名授权

点击“添加子域名授权”：

1. 选择域名。
2. 填写子域名前缀。
3. 设置有效期。
4. 选择只读或自由解析。
5. 保存。

留空前缀表示整个域名。详细规则见 [域名授权与权限](/dns/permissions)。

## 检测整域名

开启后，该用户可以对授权域名配置检测整个域名的全部子域名。默认只允许检测授权范围内的子域名。

## 封禁与删除

封禁会阻止用户登录与 API 访问，数据保留。删除会移除用户及其关联数据，执行前确认没有业务依赖。

删除用户前建议：

1. 导出该用户的个人备份。
2. 转移共享账户与域名授权。
3. 停止引用该用户的任务。
4. 吊销其 API Key。

## 常见问题

### 用户看不到统计

确认系统统计缓存已开启，并为用户开启统计缓存权限。

### 用户无法登录

检查账号状态、密码、TOTP 与封禁状态。管理员可以重置密码。

### 用户 API 返回 401

确认 API 已开启，Key 未过期、未吊销、IP 在白名单内，且账号未被封禁。
