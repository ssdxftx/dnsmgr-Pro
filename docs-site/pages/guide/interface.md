# 界面与导航

## 左侧导航

桌面端左侧是分组导航，移动端收纳为抽屉。分组顺序为：

1. 仪表盘
2. 域名管理：域名列表、DNS 账户、到期提醒、劫持检测
3. CDN 管理：CDN 账户、CDN 域名、CDN 站点设置、缓存刷新、自动预热、数据统计
4. 容灾切换：运行概览、切换策略、定时切换
5. CF 优选 IP：优选设置、任务管理
6. SSL 证书：证书账户、CNAME 代理、证书订单、自动部署账户、自动部署任务、自动续签设置
7. 系统设置：系统设置、用户管理、备份与恢复、操作日志、关于

菜单会根据当前用户等级隐藏无权限页面。普通用户获得统计权限后可以单独看到数据统计。

## 顶部栏

顶部栏显示当前页面标题、分组名称、实时时钟、在线状态和用户菜单。用户菜单包含：

- 偏好设置：界面语言、API Key。
- 安全设置：TOTP 两步验证。
- 语言：简体中文 / English。
- 退出登录。

## 列表页通用操作

大多数列表页提供统一交互：

- 搜索与筛选。
- 批量选择与批量操作。
- 刷新、重置。
- 行内详情、编辑、删除。
- 分页与空状态提示。

危险操作通常需要二次确认。删除云端资源、恢复备份、吊销证书等不可逆操作会额外要求输入确认词。

## 主题与语言

浅色与深色主题在侧边栏底部切换。语言偏好保存到账号，登录后从服务端恢复。首次访问会根据浏览器语言自动选择。

## 移动端

页面在平板和手机上自动调整。表格会切换为响应式卡片或横向滚动，常用按钮保持可点击。复杂配置建议在桌面端完成。

## 通知与公告

公告由管理员在“系统设置 → 公告管理”发布，登录后以弹窗展示。公告支持普通、成功、提醒、重要四种类型，并可设置生效时间与排序。
