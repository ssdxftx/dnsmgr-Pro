# 核心概念

理解下面几个对象，后续模块的操作会更容易定位。

## DNS 账户与域名

DNS 账户保存服务商类型、访问凭证和账户名称。一个账户可以对应多个域名。

域名是本地纳管对象，接入时需要选择 DNS 账户并从云端拉取。域名行保存分类、备注、到期时间、提醒开关和是否隐藏等属性。解析记录保存在云端 DNS，系统通过账户凭证读写。

常用关系：

```text
DNS 账户 1 ── n 域名 1 ── n 解析记录
域名 1 ── n 子域名授权
域名 1 ── n 别名、权重、解析日志
```

## 共享账户与私有账户

管理员在“DNS 账户 / CDN 账户 / 证书账户”中添加的账户属于站点共享资源，可被授权用户使用。

普通用户可以在“备份与恢复 → 凭证保险库”中创建私有账户。私有凭证只对创建者可见，管理员也无法查看明文。口令模式与便捷模式的安全边界不同，详见 [凭证保险库](/ops/vault)。

## CDN 加速域名

CDN 加速域名是接入到 CDN 厂商的站点记录。它关联一个 CDN 账户、一个加速域名、源站、缓存规则、HTTPS 与证书方式。

接入后系统会提示配置 CNAME。部分厂商支持站点级能力，例如 EdgeOne 和 ESA 的站点、规则、源站组、负载均衡与安全策略。Cloudflare 域名还可以使用规则引擎、自定义主机名与 Tunnel。

## 证书订单

证书订单记录一次证书申请或手动导入。订单包含签发账户、绑定域名、密钥类型、验证方式、签发状态、证书与私钥、到期时间和处理日志。

订单可以：

- 自动续签。
- 导出 PEM、私钥或 PFX。
- 被一个或多个自动部署任务引用。
- 在删除 CDN 联动域名时被吊销。

## 自动部署任务

部署任务把某个证书订单的证书推送到目标平台。目标可以是面板、WAF、CDN、云厂商、SSH、FTP、S3 或本地目录。

一个证书可以被多个部署任务复用。部署成功后系统记录最后部署时间与日志，失败可按任务重试。

## 容灾切换与定时切换

容灾切换策略持续探测主记录。探测失败达到确认次数后，系统按策略切换到备用记录、暂停解析或条件开启解析。恢复后可以自动恢复主记录。

定时切换策略按每天、每周、每月或间隔执行，对指定解析记录修改值、启用、暂停或删除。两者都会写入切换记录并发送通知。

## 备份、保险库与审计

整站备份包含站点配置、用户、账户、域名、任务、审计等数据，使用独立备份密钥加密。个人备份只包含当前用户的数据。

凭证保险库用于保存普通用户的私有云账户。审计日志记录写操作的用户、模块、动作、目标、结果、IP、UA 与变更前后值。

## API Key 与会话

浏览器登录使用 JWT 会话令牌。脚本和 CI/CD 建议使用 `X-API-Key`，可限制作用域、有效期和 IP 白名单。敏感操作还可以使用短时 `X-Reauth-Token` 二次确认。

所有响应带 `X-Request-Id` 与 `X-API-Version`。写请求支持 `Idempotency-Key`，异步任务可通过 `/api/jobs` 查询，业务事件可通过事件订阅回调。
