# 故障排查

## 页面无法访问

```bash
docker ps --filter name=dnsmgr
curl -fsS http://127.0.0.1:8082/api/health
ss -tlnp | grep 8082
```

检查端口映射、防火墙、反向代理与容器状态。容器反复重启时先看日志。

## 安装令牌不正确

从日志获取：

```bash
docker logs dnsmgr-pro 2>&1 | grep -i setup
```

确认页面填写与环境变量一致。令牌区分大小写。

## SQLite 不可用

- 确认 `/app/data` 是持久化卷或绑定挂载。
- 确认目录所有者是 `1000:1000`。
- 网络文件系统改用 MySQL。
- 无法识别挂载信息时设置 `DNSMGR_DATA_PERSISTENT=1`。

## SQLite 锁文件阻止启动

确认没有第二个实例运行。异常退出后，确认进程已结束后再按运维规范处理锁文件。

## 数据库连接失败

- 容器内不要用 `127.0.0.1` 连接宿主机数据库。
- 检查数据库用户权限与数据库是否已创建。
- 检查端口、防火墙与账号密码。
- MySQL 8 的认证插件与字符集需兼容。

## 登录失败

- 确认用户名密码。
- 账号可能被临时锁定，等待后重试。
- 检查账号是否被封禁。
- 开启 TOTP 后需要输入动态口令。
- 系统时间偏差会导致 TOTP 校验失败。

## TOTP 配置异常

联系管理员重置 TOTP。系统在密钥缺失时拒绝降级为仅密码登录。

## 记录的 IP 不是客户端 IP

位于反向代理后时设置：

```bash
DNSMGR_TRUST_PROXY=true
```

或填写具体代理 IP/CIDR。确认代理传递 `X-Forwarded-For` 与 `X-Forwarded-Proto`。

## HTTPS 无法访问

- 检查证书是否有效。
- 检查代理配置与端口。
- 检查 HSTS 是否导致浏览器强制 HTTPS。
- 检查 CDN 回源协议与证书。

## 证书一直验证中

- 检查 `_acme-challenge` TXT 记录。
- 使用公共 DNS 查询确认生效。
- 检查 CNAME 代理是否生效。
- 查看订单处理日志。
- 注意 Let's Encrypt 速率限制。

## CDN 证书部署失败

- 证书订单是否已签发。
- 部署账户权限是否足够。
- 域名归属验证是否通过。
- CDN 是否支持该证书类型。
- 查看部署任务日志与 CDN 证书状态。

## CDN 缓存不生效

- 检查缓存规则与 TTL。
- 检查 CDN 是否遵循源站缓存头。
- 检查查询参数、Cookie 与登录态。
- 查看响应头 `Cache-Control` 与 `Age`。

## 自动任务没有执行

- 任务是否启用。
- 运行时段是否允许。
- 调度器是否运行。
- 目标记录或账户是否仍存在。
- 查看任务上次执行与错误。

## 备份恢复后仍在维护模式

确认恢复已完成。可以重试或输入 `EXIT` 退出维护模式。退出前确认数据状态。

## API 返回 429

触发限流。读取 `Retry-After`，降低请求频率，或调整 `DNSMGR_API_KEY_RATE_LIMIT`。

## API 返回 401

- 会话令牌过期。
- API Key 已吊销或过期。
- IP 不在白名单。
- 账号被封禁。

## 页面样式或语言异常

清除浏览器缓存后重新加载。语言偏好保存在账号中，可以在用户菜单切换。

## 收集诊断信息

```bash
docker version
docker logs --tail=500 dnsmgr-pro
curl -sS http://127.0.0.1:8082/api/ready
```

同时记录操作时间、请求 ID 与相关模块。
