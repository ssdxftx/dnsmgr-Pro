# Cloudflare Workers 版可补齐功能报告

- 版本：0.31.0
- 日期：2026-11-24
- 对比基线：`backend/src/routes/*`、`backend/src/lib/*`、`frontend/src/*`
- 范围：只列 Cloudflare Workers 运行时可以实现、且对现有前端或运维有价值的功能。受运行时或厂商接口限制、无法实现的能力不列入。

## 1. 现状

Workers 版已经覆盖主链路：

- 认证、TOTP、API Key、用户管理
- 22 种 DNS 厂商
- 域名、解析记录、批量导入、记录日志
- Cloudflare Tunnel、Cloudflare for SaaS、CF Rules
- 12 种 CDN 厂商核心能力
- 证书订单、ACME、云证书、证书部署 48/51 适配器
- 备份、事件、任务、通知、审计、公告、系统设置
- 旧版 API 与域名快捷登录

当前可补齐项集中在权限、账户配置回显、证书、CDN 云端化、备份、事件、系统设置和旧版 API 兼容。

已完成 P0 五项，以及证书、CDN 站点、CDN 统计、CDN 预热、备份、DNS 检测、事件触发、系统设置、旧版 API、前端契约、公告仪表盘、注册流程、任务中心、CDN 高级能力、工程配套等全部报告项。

## 3. P0 功能

### CF-F01 权限模型落地（已完成 2026-11-24）

**现状**

- `permission` 表只用于用户编辑页展示，没有参与域名和记录鉴权。
- `visibleAccount`、`visibleCdnAccount`、`visibleCertAccount` 对共享账户直接放行。
- 记录列表固定返回 `writable: true`。

**实现方案**

- 共享账户仅管理员可见；私有账户仅所有者可见。
- 域名列表按 permission 收口，支持整域名授权、子域名授权、只读授权。
- 记录列表按子域名范围过滤，返回真实 `_access.readonly`。
- 记录新增、修改、删除、状态、备注、批量操作统一校验写权限。
- CDN 创建、证书订单、部署任务复用同一套可见性判断。

**验收**

- 普通用户无法通过 aid 访问共享 DNS/CDN/证书账户。
- 只读用户看不到写按钮，直接调用写接口返回 403。
- 子域名授权用户只能看到和修改授权范围内的记录。
- 管理员只能看到共享账户和自己的私有账户。

### CF-F02 账户配置掩码回显（已完成 2026-11-24）

**现状**

- DNS 账户列表不返回 `config`。
- CDN 账户列表不返回 `config`。
- 普通证书账户不返回 `config`。
- 前端编辑账户时配置为空，必须重新填写全部密钥。

**实现方案**

- 列表返回 `maskConfig(config)` 和 `config_state`。
- 保存时识别掩码值，保留原密钥。
- 增加 `config_error` 状态，配置解密失败时前端可提示重新填写。
- 部署账户继续使用现有掩码逻辑。

**验收**

- 打开编辑弹窗能看到非敏感字段和掩码密钥。
- 不重新输入密钥也能保存名称、备注和非敏感配置。
- 接口响应不包含明文密钥。

### CF-F03 API Key 作用域与 IP 白名单（已完成 2026-11-24）

**现状**

- 作用域只到模块，`dns:read` 可以执行写操作。
- IP 白名单只做字符串精确匹配，CIDR 不生效。
- Key 前缀为 `dmk_`，与服务器版 `dnsmgr_` 不兼容。

**实现方案**

- 按 HTTP 方法区分 read/write。
- 补齐模块映射：auth、apikeys、dns、cdn、cert、deploy、cloudflare、monitor、schedule、optimize、dnscheck、expire、backup、vault、users、system、audit、jobs、events、general。
- 支持 IPv4/IPv6 CIDR。
- 同时接受 `dmk_` 和 `dnsmgr_` 前缀，兼容已有 Key。
- API Key 不能创建或修改超过自身作用域的新 Key。

**验收**

- `dns:read` 对 POST/PUT/DELETE 返回 403。
- `10.0.0.0/8` 能匹配 `10.1.2.3`。
- 服务器版已有 Key 可以直接使用。

### CF-F04 认证加固（已完成 2026-11-24）

**现状**

- 登录没有失败计数、锁定和限流。
- TOTP 没有已用口令表，存在重放窗口。
- JWT 没有 `jti` 和 `token_version`，logout 不吊销令牌。
- 二次确认令牌没有绑定操作类型和会话。

**实现方案**

- 增加登录失败计数和 15 分钟锁定。
- 增加 `totp_replay` 表，记录已使用动态口令。
- JWT 增加 `jti` 和 `token_version`，增加 `token_revocation` 表。
- logout 写入吊销记录；logout-all 自增 `token_version`。
- 二次确认令牌绑定 `sid` 和 `op`。
- 重新绑定或关闭 TOTP 时要求当前动态口令，并自增令牌版本。
- API Key 不允许修改 TOTP 配置。

**验收**

- 连续错误密码触发锁定。
- 同一 TOTP 口令不能重复使用。
- 登出后旧令牌立即失效。
- 二次确认令牌不能跨操作复用。

### CF-F05 用户删除清理（已完成 2026-11-24）

**现状**

- 删除用户只删除 `permission` 和 `users`。
- 私有账户、域名、CDN、证书、任务、API Key、备份会残留。

**实现方案**

- 删除用户前清理其私有 DNS/CDN/证书账户及名下资产。
- 清理 `api_key`、`dmtask`、`sctask`、`optimizeip`、`dns_check_task`、`backup_job`、`backup_chunk`、`permission`。
- 清理共享域名上属于该用户的任务和授权。
- 使用 D1 batch 保证同一批清理按顺序执行。

**验收**

- 删除用户后不再有该用户的 API Key、私有账户、域名、任务和备份记录。
- 共享账户和共享域名不受影响。

## 4. P1 功能

### CF-F06 证书能力补齐（已完成 2026-11-24）

**现状**

- ACME 仅支持 RSA。
- ACME 不使用 `cert_cname` 委派。
- 云证书订单不会自动续签。
- 证书 CNAME 创建时忽略 `cnamedomain`。

**实现方案**

- 使用 WebCrypto 或 ASN.1 库生成 ECDSA P-256/P-384 密钥和 CSR。
- ACME DNS-01 支持 `cert_cname` 委派：优先使用已启用的 CNAME 记录。
- cron 增加腾讯云、阿里云、UCloud 证书订单自动续签。
- 修正证书 CNAME 创建、检查和删除逻辑。
- 证书账户列表返回掩码配置。

**验收**

- ECC 订单可以签发。
- 配置 CNAME 委派的域名可以通过 ACME 验证。
- 云证书到期后能自动续签。
- 证书 CNAME 状态检查结果与配置目标一致。

### CF-F07 CDN 站点以云端为准（已完成 2026-11-24）

**现状**

- `/api/cdn/zones?aid` 只读本地 `cdn_zone`。
- 云端已有站点需要先执行同步才能看到。
- `/api/cdn/zones/setting` 只保存到本地，不下发厂商。

**实现方案**

- `/cdn/zones?aid` 优先查询厂商站点列表，失败时回退本地缓存。
- 同步结果写入 `cdn_zone`，保留本地域名聚合。
- `/cdn/zones/setting` 读取云端配置，计算差异后调用 `updateZoneSetting`。
- 本地只保存缓存和最近一次同步状态。

**验收**

- 新账号未手动同步也能看到云端站点。
- 修改站点配置后云端生效。
- 厂商接口失败时返回明确错误，并保留本地缓存。

### CF-F08 CDN 统计补齐（已完成 2026-11-24）

**现状**

- `GET /api/cdn/statistics` 返回空 series。
- 统计缓存只在 isolate 内存中，重启后丢失。
- 统计接口对任意登录用户开放。

**实现方案**

- 实现基础统计聚合，复用现有 12 家厂商统计函数。
- 增加 `cdn_stat_cache` 表或复用 `app_setting` 保存最近一次统计结果。
- cron 按 `cdn_stats_cache_interval` 刷新缓存。
- 统计接口要求管理员或 `stat_cache=1`。

**验收**

- 统计页能显示基础流量、带宽、请求、命中率。
- 缓存刷新后数据持久化。
- 普通用户未授权时返回 403。

### CF-F09 CDN 预热与缓存任务（已完成 2026-11-24）

**现状**

- 定时预热任务只写 `cdn_cache_task` Mock 记录。
- 缓存任务重试只改状态，不重新提交云端。

**实现方案**

- `runPreheatTask` 按 URL 匹配 CDN 账户，调用真实 purge/preheat。
- 缓存任务保存 provider、账户、请求参数和云端任务 ID。
- 重试时重新调用厂商接口，并更新结果。
- 失败任务记录错误和重试次数。

**验收**

- 定时预热后云端能看到刷新/预热任务。
- 重试会真正重新提交，不是只改本地状态。

### CF-F10 CDN 高级能力按厂商接入（已完成 2026-11-24）

**现状**

- EdgeOne 函数、KV、安全、共享 CNAME、别名域名、错误页、多通道、推理、媒体转码、账单与套餐均已真实下发。
- ESA 源站组、负载均衡、四层代理、刷新/预热任务按已开放接口真实下发。
- 其他厂商或未开放能力保留 `cdn_resource` 本地持久化。

**实现方案**

- EdgeOne 高级能力按官方 API 逐项接入，并在云端失败时直接返回厂商错误。
- 本地持久化资源统一返回 `source=local`、`local=true`，列表响应同样携带来源标识，前端据此显示“本地配置”。
- 补齐 EdgeOne `DescribePurgeTasks`、`DescribePrefetchTasks` 任务查询。

**验收**

- EdgeOne/ESA 已开放接口操作可在云端控制台看到结果。
- 本地持久化能力有明确 `source` 标识，不伪装成云端下发。

### CF-F11 备份能力补齐（已完成 2026-11-24，归档根密钥平台托管）

**现状**

- 导入只支持个人备份。
- 恢复没有维护模式、快照和会话失效。
- 备份密钥不能轮换。
- S3 列表和连接测试使用未签名请求。
- 个人备份按原 ID 写回，没有 ID 重映射。

**实现方案**

- 支持整站备份导入。
- 恢复前进入维护模式，恢复后退出；恢复前生成快照。
- 恢复后自增 `token_invalid_before` 或 `token_version`，使旧会话失效。
- 备份密钥支持轮换，使用新密钥重新加密。Workers 版归档根密钥由平台 `CONFIG_KEY` 托管，轮换接口返回平台托管说明，运行时不对根密钥做热轮换。
- S3 列表和测试改用 SigV4 签名。
- 个人备份导入做 ID 重映射，避免覆盖其他用户数据。
- 备份目标列表返回掩码配置。

**验收**

- 整站备份可以导入并恢复。
- 恢复期间业务接口返回维护提示。
- 私有 S3 Bucket 可以列出和测试。
- 导入个人备份不会覆盖其他用户同 ID 数据。

### CF-F12 DNS 检测补齐（已完成 2026-11-24）

**现状**

- `notice_email` 保存后不发送。
- 定时任务使用系统用户 id=0，私有账户任务会失败。
- 缺少权限、子域名范围、限流和分布式锁。
- 没有代理检测。

**实现方案**

- 检测完成后按 `notice_email` 或系统通知邮箱发送告警。
- 定时任务使用任务所有者身份访问账户。
- 增加权限、子域名范围、限流和任务锁。
- 使用现有 Cloudflare IP 段判断代理状态，输出 `proxied` 结果。

**验收**

- 检测异常时能收到邮件。
- 私有账户定时任务正常执行。
- 普通用户只能检测授权域名和子域名。
- 代理记录能标记为 `proxied`。

### CF-F13 事件触发（已完成 2026-11-24）

**现状**

- 事件订阅 API 可用，但业务代码不触发。
- 只有手动测试会发送。

**实现方案**

- 在证书签发、证书失败、部署成功、部署失败、备份完成、容灾切换等位置调用事件发送。
- 使用 `event_delivery` 记录投递结果。
- 增加失败重试和并发限制。
- 保持现有 HMAC 签名格式。

**验收**

- 订阅 `cert.order.issued` 后，证书签发能收到回调。
- 失败投递有记录，并按策略重试。
- 事件风暴不会无限并发。

### CF-F14 系统设置补齐（已完成 2026-11-24）

**现状**

- `GET /api/system/settings` 返回原始密钥。
- `stat-cache-refresh` 只写时间戳。
- cron 只校验 key，不校验 `cron_type`。
- QQ 凭据变更后不会清空 openid。
- 缺少 `mail_name2` 兼容。

**实现方案**

- 系统设置返回掩码值，保存时忽略掩码。
- 实现统计缓存刷新。
- cron 支持 `cron_type`、`x-cron-key`、`Authorization: Bearer` 和 query key。
- QQ AppID/Secret 变更后清空 `qqbot_openid`。
- 兼容 `mail_name2` 写入 `mail_name`。
- 保存设置时记录审计变更。

**验收**

- 设置页不再显示明文密钥。
- 手动刷新统计缓存后数据更新。
- 外部 cron 使用 Bearer 或 query key 都能触发。
- 修改 QQ 凭据后需要重新绑定。

### CF-F15 旧版 API 与快捷登录（已完成 2026-11-24）

**现状**

- 旧版 API 不校验权限和记录归属。
- `minTTL` 硬编码。
- quicklogin 使用 `jwtSecret()`，与服务器版 `sys_key` 不兼容。
- quicklogin 只读标记按归属推导。

**实现方案**

- 旧版域名列表按 permission 收口，并过滤 `is_hide`。
- 记录修改、删除、状态、备注校验记录归属和子域名写权限。
- `minTTL` 从 provider 读取。
- quicklogin 支持 `sys_key` 配置，并兼容现有 JWT 密钥。
- quicklogin 只读标记按整域名授权和只读授权计算。

**验收**

- 普通用户只能看到授权域名。
- 只读用户通过快捷登录不能写记录。
- 旧版客户端签名和现有链接可以继续使用。
- `minTTL` 与厂商能力一致。

### CF-F16 前端契约对齐（已完成 2026-11-24）

**现状**

- 账户编辑缺少 `config`。
- 记录页 `_access` 永远可写。
- CDN 站点页看不到未同步的云端站点。
- 统计页基础接口为空。

**实现方案**

- 补齐账户 `config`、`config_state`、`config_error`。
- 记录列表返回真实 `_access`。
- `/cdn/zones?aid` 返回云端站点。
- 补齐 `GET /api/cdn/statistics`。
- 统一 `can_freecert`、`can_certapply`、`can_certlink` 的账户能力判断。

**验收**

- 账户编辑弹窗正常回显。
- 只读用户界面不显示写操作。
- CDN 站点页和统计页有数据。
- 证书按钮按账户能力显示。

## 5. P2 功能

### CF-F17 公告与仪表盘（已完成 2026-11-24）

**实现方案**

- 公告新建默认 `active=1`，PUT 支持局部更新，补齐时间格式校验。
- 仪表盘普通用户按 permission 统计域名、账户、CDN 域名。
- 普通用户不返回全站用户总数。

**验收**

- 公告新建后默认启用。
- 普通用户仪表盘只统计授权资产。

### CF-F18 注册流程（已完成 2026-11-24）

**实现方案**

- 邮箱验证码增加失败次数上限和 24 小时发信上限。
- 注册码和验证码消耗与建号使用 D1 batch 保证同批执行。
- 撞名时按服务器版逻辑消耗一次验证码尝试。

**验收**

- 验证码不能被无限尝试。
- 建号失败不会留下已消耗但未使用的凭据。

### CF-F19 任务中心（已完成 2026-11-24）

**实现方案**

- 到期扫描、备份、证书批量处理等长任务写入 `async_job`。
- 使用 `waitUntil` 或 cron 推进任务状态。
